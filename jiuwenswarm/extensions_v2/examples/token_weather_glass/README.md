# TokenWeather 状态条

插件名称和设置项在中英文界面中统一为 `TokenWeather`；状态条以天气图标和状态开头，不重复显示品牌标题。

独立的 AgentServer 域 V2 插件 `webui.token-weather-glass`，不修改原 Token Weather 或工作台。需使用包含客户端布尔偏好和 settings location 接口的宿主版本。

在输入框上方展示 `ops.session.usage()` 提供的已观测上下文 Token/窗口/占比，以及存在时的额度和美元费用。未知字段不编造，真实零值保留。监听 `context.usage.updated` 刷新，重新挂载时重新查询；它不是提供商账单。

数值格式跟随宿主上下文浮层：已用 Token 按 1000 换算为 K，上限按 1024 换算为 K/M，最多一位小数并省略末尾零。已知 Token 和上限时计算一位小数的占比，例如 `8.9% · 23.2K/256K Token`。

天气按未舍入的上下文占用分级：低于 25% 为 `☀ 晴朗`，25%～不足 50% 为 `☁ 多云`，50%～不足 75% 为 `☂ 阵雨`，75%～不足 90% 为 `☇ 风暴`，90% 及以上为 `↯ 即将压缩`。状态和数字使用同一占比来源；占比未知时不显示天气，真实零值显示晴朗。“即将压缩”表达高占用，不保证宿主实际压缩时点。

状态条复用宿主公共组件和主题样式，不声明自定义颜色、渐变、模糊、圆角或阴影；“打开详情”在右侧打开插件独立 Tab。

## 趋势与详情

状态条附带最近 12 个已观测轮次的上下文迷你趋势和上轮增减。上下文下降可来自压缩，不代表本轮消耗为负。“打开详情”通过通用 Button.openPanel，在当前客户端打开或重新打开同会话的详情 Tab；后台刷新不抢占用户选择。

详情由插件生成中英文 iframe 文档，不加载外部资源或脚本。上方保留用量总览，中间按轮次展示上下文组成堆叠柱，下方保留输入、输出、缓存命中、总消耗与上下文的精确明细表。通过已有 `ops.session.usage(breakdown="summary")` 采集同轮分类快照，系统提示词、工具及连接器、技能、对话消息的顺序与配色对齐浮层；悬停或键盘聚焦柱子查看精确分类值。分类合计与权威上下文总量分开，不缩放分类来凑总数；未采集的轮次明确标记，真实零值保留。缓存命中属于输入，不重复加入消耗总量。同一 request_id 不新增轮次，保留窗口内更新原柱，已移出窗口的旧请求不重新进入图表。页面刷新、开关关闭和 Tab 关闭不清空当前插件进程内的历史；插件重载或进程重启后重新采集，不读取宿主私有日志或用当前分类补历史。

宿主需支持 ops.ui.create_resource_dir / asset_url / release_resources、Iframe.src 的完整双语地址/标题以及 Button.openPanel。HTML 模板与 CSS 在 assets/ 中随插件发布；详情由插件生成不可变文件，WebUI 消息只传资源 URL。图表与详情业务均在本插件中；宿主只提供通用渲染和导航。

详情通过 `Iframe.minWidth: 360` 声明最小宽度。面板不足 360px 时，宿主提供横向滚动；较宽时随面板伸展，无需切换宽度模式。

## 显示开关

通过 manifest `web.slot.contribution`、`slot: application.settings`、`scope: application` 和 location 定位到“设置 → 常规 → 显示设置”。默认开启，关闭时同步隐藏状态条与已打开的“用量详情”页签，设置开关始终可见，可重新开启。用量历史和后台观测保留；重新开启不自动选中详情页。宿主需支持 UiRenderInput.visible_when。偏好按包隔离，保存在当前浏览器/桌面客户端，适用于所有会话并在重启后保留；同源标签页同步，不跨设备同步。

设置行标题、描述、状态条、按钮与无障碍标签均提供独立的中英文文案，跟随宿主当前界面语言即时切换。切换语言保留显示开关状态和用量。只有窗口容量已知时显示“上下文上限”，不将它作为已消耗 Token 数。保存失败时宿主提示错误并保留原值。

## 打包和安装

从仓库根目录执行（output 可换为任意目标文件）：

```bash
uv run python jiuwenswarm/extensions_v2/examples/token_weather_glass/pack.py --output /tmp/token-weather-glass.zip
```

ZIP 根目录包含 manifest.yaml，通过宿主现有 V2 包安装入口安装。该示例不随源码自动启用；当前运行服务需要包含对应宿主接口。卸载插件不删除客户端的展示偏好。
