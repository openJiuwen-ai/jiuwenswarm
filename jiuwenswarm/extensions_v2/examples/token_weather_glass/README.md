# TokenWeather

在对话输入框上方实时展示当前会话的上下文用量，帮助判断距离窗口上限还有多少空间。

## 功能

- **实时状态条**：展示已用 Token、窗口上限与占比，并附带最近 12 轮的变化趋势。
- **天气状态**：占用低于 25% 为晴朗，25%–50% 多云，50%–75% 阵雨，75%–90% 风暴，90% 以上为即将压缩。
- **用量详情**：点击“打开详情”，在右侧面板查看按轮次拆分的上下文组成与精确明细。
- **显示开关**：在“设置 → 通用 → 显示”中控制状态条是否出现。

## 生效机制

- 每轮对话结束、上下文用量更新时，插件都会收到通知并刷新状态条。
- 用量来自当前会话已经记录的数据：只展示真实观测到的值，未知的字段留空，真实的 0 照常显示。
- 刷新页面会重新读取当前会话；插件重载或进程重启后会重新收集历史。
- 状态条沿用平台主题，不另设颜色、渐变或阴影。

## 说明

- 展示的是已观测的上下文用量，不是提供商账单。
- 上下文下降可能来自压缩，并不代表本轮消耗为负。
- 插件按会话隔离数据，切换会话时展示对应会话的用量。
