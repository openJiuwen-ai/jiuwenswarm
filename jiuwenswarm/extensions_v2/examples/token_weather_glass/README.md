# TokenWeather

在对话输入框上方实时展示当前会话的上下文用量，帮助判断距离窗口上限还有多少空间。

## 功能

- **实时状态条**：展示已用 Token、窗口上限与占比，并附带最近 12 轮的变化趋势。
- **天气状态**：占用低于 25% 为晴朗，25%–50% 多云，50%–75% 阵雨，75%–90% 风暴，90% 以上为即将压缩。
- **用量详情**：点击“打开详情”，在右侧面板查看按轮次拆分的上下文组成与精确明细。
- **显示开关**：在“设置 → 通用 → 显示”中控制状态条是否出现。

## 生效机制

1. 插件监听 `context.usage.updated`，每次收到用量更新时刷新状态条。
2. 数据来自 `ops.session.usage()`，只展示宿主已观测到的字段，未知值不补造，真实零值保留。
3. 页面刷新后重新查询当前会话；插件重载或进程重启后重新采集历史。
4. 状态条复用宿主主题样式，不声明自定义颜色、渐变或阴影。

## 说明

- 展示的是已观测的上下文用量，不是提供商账单。
- 上下文下降可能来自压缩，并不代表本轮消耗为负。
- 插件按会话隔离数据，切换会话时展示对应会话的用量。

## 安装

在仓库根目录执行：

```sh
python jiuwenswarm/extensions_v2/examples/token_weather_glass/pack.py --output /tmp/token-weather-glass.zip
```

通过插件详情页安装后即可生效；卸载插件不会删除客户端的展示偏好。
