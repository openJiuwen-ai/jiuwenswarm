# TokenWeather

## Register

product

## Users

JiuwenSwarm users composing a message and checking context usage without leaving their conversation.

## Product Purpose

Provide a compact, independently installable usage plugin, using observed platform data. The plugin owns usage content and interaction; the host provides shared components, theme styles and settings placement.

## Brand Personality

Precise and calm. Reuse the host's existing visual language for the bar.

## Anti-references

Avoid visible grids, stripes, repetitive textures, flashing decoration, made-up usage readings, or plugin-specific themes embedded in host code.

## Design Principles

- Keep usage legible and distinguish unknown readings from zero.
- Reuse shared host components and theme styles for the bar without custom background parameters.
- Open usage details through an explicit button; background updates must not reopen or select tabs.
- Let the client-wide display preference survive restart without changing plugin activation.
- Reuse host settings menus, sections and rows through location declarations.

## Accessibility & Inclusion

Use a labeled keyboard-operable details button and static decoration. Provide separate Chinese and English display and accessible text, selected by the application's current interface language. Preserve the display preference when the language changes. Allow compact content to wrap in narrow containers.
