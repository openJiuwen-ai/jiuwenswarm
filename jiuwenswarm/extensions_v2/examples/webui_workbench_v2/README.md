# 插件交互工作台

一个覆盖 WebUI 主要插槽与组件的演示插件，用来展示插件如何向页面的不同位置注入界面。

## 功能

- **应用入口**：首次进入时展示欢迎卡片，可关闭。
- **侧栏入口**：新增“交互工作台”主页面与底部用户菜单。
- **任务区入口**：新增“任务检查”页面。
- **对话辅助**：输入框下方快捷按钮、右侧“工作区文件”和“网页预览”页签。
- **轮次信息**：展示本轮 Token 用量，提供刷新与详情操作。
- **页头状态**：在会话标题旁展示工作台状态，并提供刷新按钮。

## 生效机制

- 每个界面位置都写在 `manifest.json` 的 `ui.items` 里，说明放在哪里、由哪种渲染器呈现。
- 插件安装并激活后，页面按这份声明把内容放到对应位置；页面打开时由插件后端返回具体内容。
- 工作区文件页签读的是当前会话的目录，内容随会话变化。
- 应用级位置不依赖会话，打开应用就能看到；对话里的位置要进入真实对话后才出现。

## 说明

- 示例不调用模型或外部业务 API，仅演示插槽、组件与交互协议。
- 主页面、任务页面与网页预览使用 `Iframe`，文件页签使用 `FileTree` 与 `FilePreview`。
- 界面树由后端完整下发，组件自行处理展开、选中与提示文案。
