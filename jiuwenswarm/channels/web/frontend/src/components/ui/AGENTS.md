# 通用 UI 组件规则

本目录同时包含 `Switch`、`Input` 等基础控件，以及 `PageToolbar`、`FilePreviewPanel` 等通用组合组件。目录位置不改变组件现有职责；不要把业务状态或领域决策加入基础控件。

- 修改共享组件前，检查其公开接口和受影响的调用方。只在需求适用于这些调用方时修改共享行为；特性专属的组合或布局留在特性中。
- 新增通用控件前，先查看 `index.ts` 的现有导出和相近组件。复用语义与交互一致的组件；确实需要不同能力时，明确新组件与已有组件的适用边界。
- 保持现有键盘操作、焦点、无障碍名称、禁用状态和响应式行为；新增用户可见文案遵守前端根规则的中英文国际化要求。
- 样式使用前端语义主题变量，不为单个特性的外观覆盖所有调用方的共享样式。具体组件属性以源码中的类型定义为准，不在本文件维护组件清单。
