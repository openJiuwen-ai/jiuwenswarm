# 科研工作台架构

## 已运行的路径
公开论文 → 固定PDF及页面片段 → 已冻结研究问题与2×2实验 → 已保存模型输出 → 评分来源确认 → 固定口径统计 → 图表及ICLR源码 → 离线PDF。

`execution.py`/`fulltext_runner.py`使用openJiuwen模型适配器。正式实验的五个冻结执行模块、题目与语料不得随结果变化改动。每次模型调用先预留费用，记录请求、用量与错误，默认没有自动重试。

`pipeline.audit`重新检查冻结协议、192个答案与1440个产物。`review_scoring`区分原始队友评分、个人声明和项目用户统一接受；后者不能证明独立评审。四条非主指标引用判断仍为null。

`paper_artifacts.assemble`只在新目录生成材料。统计、源码、评分输入、图表及PDF有哈希绑定；修改输入后必须重新生成。图表由Matplotlib读取相同评分生成，不凭文字估算。

## 原生接入
JiuwenSwarm普通聊天适配器将本地插件工具装入真实DeepAgent。演示脚本依次调用audit、prepare、draft，随后在本机离线编译并核验。它实际经过原生工具注册与调用，不是只打印一段模拟流程。

## 人工与自动边界
| 环节 | 当前实现 |
|---|---|
| 选题、研究问题、方案 | 用户/队友与编码助手共同确定；没有验证自动发现新问题 |
| 文献取得、命题核查 | 已取得固定版本，原件有记录；不是演示时重新联网检索 |
| 模型实验 | 已真实执行384请求；演示复用已有结果，不重跑 |
| 答案评分 | AI辅助队友材料及用户统一接受，个人独立性未核实 |
| 审计、统计、图表、源码与PDF | 演示中自动完成 |
| 最终学术审阅、Reviewer、比赛提交 | 人工决定与外部操作，未由本演示执行 |

当前贡献是可核验的半流程科研材料生成和证据管理，不宣称Team自动科研或已证明方法提升。
