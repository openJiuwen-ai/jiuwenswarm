## 背景

工作区 getter 已集中工作区名称及 Provider 分发，但默认物理根仍散落
`base / "agent"`。本次只复用既有相对目录 getter，保持路径值和插件边界不变。

## 决策

- `get_agent_root_relative_dir()` 保持固定、无副作用的 `Path("agent")` 返回值。
- 当前默认物理根拼接改用该 getter；保留每个调用点的父目录、租户参数、延迟导入和
  `use_provider=False`。全局路径不改成租户路径，也不增加 Provider 调用。
- 历史目录识别和迁移源、包内模板、接口逻辑路径及虚拟树节点保留固定约定。
- 旧文件接口的物理根仍位于原全局数据根下；只替换物理拼接，保留逻辑路径和安全边界。

## 拒绝的方案

- 全量替换所有 `agent`：会混淆历史布局、模板布局、接口协议与当前物理布局。
- 用 `get_agent_root_dir()` 替换整段路径：会改变原父目录，或引入请求绑定和插件分发。
- 将相对 getter 插件化或改成绝对路径：会破坏相对目录调用方和启动前的静态布局语义。
