# Todo 初始化检查的会话间等待隔离

| 项 | 值 |
| --- | --- |
| 类型 | bugfix |
| 日期 | 2026-11-10 |
| 关联规约 | S_03 N14 |

Flash 每次提交前检查 Todo 首次初始化依据。原实现先持进程级 `_FILE_LOCK`，再等待单会话 metadata 文件锁；即使该会话已初始化，另一个独立会话仍会被拖住。

检查改为只持所属 metadata 文件的 portalocker 锁。同会话跨线程/跨进程的读取、消费与 fsync/replace 仍在该文件锁内；异步元数据写入继续在自己的文件锁内合并，不能重置已消费标记。缓存失效仍在文件操作后按原规则执行。

回归以事件阻塞会话 A 的锁入口，确认 B 可独立完成；同时保留同会话竞争、跨进程竞争、异步旧写与绑定回滚测试。原始失败及修复结果见工程根 `Checkpoint/debug/tools_failure_analysis/validation_20261110/fix-implementation/`。不更改通用元数据队列或初始化标记的业务语义。
