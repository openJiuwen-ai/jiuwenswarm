# 终帧倒推 · 定格前最后几秒

Designer 视频生成风格之一（`video_style=final_frame_reverse`）。

## 目标

把经典名画、电影级定格图或角色定格图，改造成约 10–15 秒短视频。
核心不是讲完整故事，而是拍出「最终定格画面形成之前的最后几秒」。

## 公式

最终参考构图作为终点 → 倒推出形成该构图之前的动作链 → 伪一镜到底建立空间和推进 → 特写强调神态、动作、物件 → 视觉母题完成转场 → 最后一秒收束为参考图构图。

## 硬规则

1. 参考图 / 名画构图 = 视频最后约 1 秒的**终帧**，不是开场。
2. 不要纯一镜到底：长镜头负责空间/气势/推进；特写负责神态、关键动作、关键物件与情绪落点。
3. 不要围绕已完成的静态画面旋转展示（禁止 turntable / 模型展示感）。
4. 每次切镜必须有视觉母题转场：烟尘、雨丝、旗布、羽毛、圣光、布料、枪火、人物擦镜、栏杆线条、倒影、云雾等。
5. 节奏：前段推进冲击与空间穿越；中段特写打点；后段减速归位；最后 1 秒定格对齐参考图。
6. 最后一枚 **scene_specs** + 最后一支 **clip** 必须收束到参考构图（姿态、取景、光线）。
7. 管线用每支 **clip** 的 R2V：**character_specs** + 空 **scene_specs**；整片弧线的终点才是用户参考定格。无独立 frame/keyframe 节点。

## Brief / Storyboard 写法

- 总体指令 → 核心动作链（倒推）→ 逐 **clip** 时间轴（合计约 10–15 秒）
- 每支 **clip** 写清：画面内容、镜头运动（可写景别/运镜等电影语言）、角色动作、转场动机、情绪作用
- 负面提示 + 一句核心执行原则

## Clip（R2V）写法

- 明确本 **clip** 在整段弧线中的位置（前冲 / 中特写 / 后归位 / 终帧）
- 动作具体，禁止空泛「电影感」
- 承接上一 **clip** 的视觉母题（**shot_consistency**）
- 若为本片最后一支 **clip**：减速、归位、稳定，终帧对齐参考图构图

## 负面

静态展示环绕、无动作链、无动机硬切、全程拖慢、结尾未对齐参考图、字幕水印。
