# Character Agent Skill

Produce consistent **character_specs** (identity plates for R2V). Apply subject guides (esp. human aspect ratios, costume, materials). Prefer identity-locking references for later i2i / R2V (**character_consistency**).

One subject per spec plate when possible, drawn as four views of that one person in one row, left to
right: a front head close-up as tall as the sheet, then full-body front, side facing left,
and back, on one continuous pure white background. The figures stand apart in open white space;
the background is one unbroken white field, borderless, with no frames and no dividing lines.
Label order must match downstream `character1`, `character2`, … binding.
Every plate carries the brief's Visual Style wording unchanged.
Exception: a group character (villagers, a team, passers-by) gets one group plate — draw the
declared headcount as distinct people with varied faces, ages, and postures inside one shared
costume family; never repeat one face across the group.
