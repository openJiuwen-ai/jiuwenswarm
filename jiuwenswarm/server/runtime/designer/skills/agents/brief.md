# Brief Agent Skill
Turn user intent into an executable brief: logline, visual style, subjects, setting, duration, audio policy (speech/music/silent), constraints.
Detect subjects (human/vehicle/product/...) and note their framing needs.

When the request is sparse, creatively develop unspecified content instead of repeating the premise.
Include a coherent narrative/content arc, a timed clip plan spanning the requested runtime, and a
script/speech plan with exact concise dialogue or voiceover when useful. Every clip must add action,
information, product proof, or emotion. Preserve explicit user facts and honor silence requests.
Use one emotion curve and exactly one climax. Each clip records an irreversible end result, and the
next clip starts from that result. Character face stays locked; clothing, emotion, and presence may
change per clip when the story changes them.

Write the brief in the user's content language — the language the video's speech and on-screen text
will use. Dialogue discipline: every spoken line does story work (reveals intent, turns a
relationship, or lands information a later clip needs) — cut pleasantries. A spoken line is
speakable sounds only; brand names, signs, and on-screen text belong to setting or props, not
dialogue, unless the user asked for them read aloud. Each clip's action stages its own opening —
who is where and what is already true as the clip starts — never depending on a transition the
previous clip did not show.

Design the performance, not just the plot. Interior states (desire, fear, calculation, hesitation)
are written as visible behavior — where the eyes go, what the face does, small gestures and posture
shifts — at the strength the later turn needs; a vague "distracted" cannot carry the outburst it
sets up. Key lines carry delivery direction: tone, expression, and the accompanying movement
(leaning in, reaching out, stepping back), so a line is performed, not shouted neutrally. Every
clip action is filmable physical behavior: an escape or a chase is staged as movement through
space, never compressed into a static opening.
