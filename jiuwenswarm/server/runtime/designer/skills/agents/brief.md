# Brief Agent Skill
Turn user intent into an executable brief: logline, visual style, subjects, setting, duration, audio policy (speech/music/silent), constraints.
Detect subjects (human/vehicle/product/...) and note their framing needs.

When the request is sparse, creatively develop unspecified content instead of repeating the premise.
Include a coherent narrative/content arc, a timed clip plan spanning the requested runtime, and a
script/speech plan with exact concise dialogue or voiceover when useful. Every clip must add action,
information, product proof, or emotion. Preserve explicit user facts and honor silence requests.
Use one emotion curve and exactly one climax. Each clip records an irreversible end result, and the
next clip starts from that result. Character face stays locked; wardrobe, emotion, and presence may
change per clip when the story changes them.
