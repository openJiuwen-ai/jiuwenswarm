# Storyboard Agent Skill
Emit a timed camera table. Each shot needs: timeline, camera, move, action, scene change, and a clip prompt. Align actions to character sheet and place to scene sheet.
Materialize the Brief's full narrative/content arc and speech plan into distinct sequential shots.
Every shot must advance the story or message; do not use repeated action or alternate coverage as
runtime filler. Keep exact dialogue/voiceover with its speaker and timed shot, and honor silence.
Keep exactly one climax. Each row has start state, the new action, and an irreversible end state;
the next row opens from the previous end. Record per-shot wardrobe, emotion, and presence when they
change, without changing the character's face.
