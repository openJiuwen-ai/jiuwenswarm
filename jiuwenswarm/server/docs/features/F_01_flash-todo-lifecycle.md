# Flash Todo 初始化与旧接口接入

日期：2026-10-27。关联需求：FE20261014380870。

2026-10-28 补充：本轮只交付 Core 与 Jiuwen，Relay 固定未修改的 dev-stable。
暂停/恢复等事务内读写使用配套 SDK 的候选视图，避免旧公开 I/O 缓存装饰器暴露未提交状态；
默认事件/历史仍使用旧协议。本轮不交付 Relay 页面、缓存及历史的版本防回退增强。

新 Flash 会话仍可登记内部 `todo_initialized=False`；未先调用 session.create 的旧接入也可
首次使用 Todo，提交前可靠保存 True。已经登记后丢失文件时拒绝重新初始化；有效旧文件
可继续读取并在实际修改时登记。未知旧会话如果此前已丢失文件，无法与首次使用区分，
这是用户为优先保证增量更新与并发一致性而接受的未满足边界。

标记按已有租户会话目录隔离。跨进程文件锁保护首次登记，异步元数据回写及绑定回滚
保留已使用记录；公开读取不返回该字段。旧空会话不再要求可信清单；相关迁移工具和
登记接口已移除。普通/Code 不新增本次 guard，也不新增客户端字段或恢复协议。

WS按连接、HTTP按请求固定来自宿主身份的输出策略；旧接入缺省legacy，版本消费者需
显式配置。历史响应与Flash实时出口使用同一策略，不增加客户端请求参数或握手。

DeepResearch 的 Todo 持久化仅更新启动时捕获的计划中已经存在且名称匹配的标准阶段，
不由迟到回调创建或重建清单。Flash 在启动研究进程前捕获目标，捕获失败沿原工具失败
通路返回；已失效 owner 不能提交。未绑定 Todo 的其他调用不写 Todo，记录一次明确的
跳过原因，继续原进度推送和报告交付；已绑定但标准阶段缺失/被改名时记录原因且不写入。

契约见[运行时规约](../specs/S_03_runtime-agent-management.md)与
[请求入口规约](../specs/S_02_request-pipeline-dispatch.md)。本地验证包括实际Flash统一
工具、真实文件、首次竞争、文件丢失与恢复、旧队列/回滚保护及协议兼容。云上实际后端、
ChatService正向联调和正式固定SDK制品仍需对应环境证据，不能以本地测试替代。
