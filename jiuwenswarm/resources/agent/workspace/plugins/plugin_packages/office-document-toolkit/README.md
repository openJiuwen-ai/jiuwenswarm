# 办公文档能力包 (Office Document Toolkit)

支持 PDF、Word、Excel、PPT 文档解析、内容处理与文件生成，实现文档整理、数据汇总与报告输出。

## 核心能力

- **文档解析**：解析 PDF、Word、Excel、PPT 文件，提取文本、表格与结构化内容
- **文档生成**：根据结构化内容与模板生成 PDF、Word、Excel、PPT 文件
- **数据汇总**：聚合多源数据，自动整理、分类、统计并生成结构化报告

## 使用方式

在 JiuwenSwarm 插件中心安装并启用本插件，对话输入区勾选插件 chip（可配合任意专家），然后发送推荐问法。
