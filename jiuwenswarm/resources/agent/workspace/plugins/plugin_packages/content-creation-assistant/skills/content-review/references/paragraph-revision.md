# Paragraph Revision / 逐段修改反馈

对文稿逐段给出修改反馈和可直接替换的修订文本的工作流程。

## 核心原则

**逐段诊断 + 可替换修订**：每一段都给出具体诊断和可直接替换的修订文本，不只说"这里需要改"。

## 审阅范围确认

- 用户明确指定了段落范围时，只审阅指定范围。
- 用户说"全文审阅"或未指定范围时，声明最小审阅范围（如"我将逐段审阅第1-10段"），然后开始。
- 不再次索取已确认的范围确认。

## 逐段反馈格式

对每一段，按以下结构给出反馈：

### 段落诊断
- **段落编号**：第 N 段
- **原文摘要**：一句话概括本段内容（不复制全文）
- **诊断结果**：从以下维度评估

| 维度 | 检查要点 |
| --- | --- |
| 内容充实度 | 是否有实质信息，还是空话套话 |
| 逻辑连贯性 | 段内逻辑是否自洽，与前后段是否衔接 |
| 表达清晰度 | 句子是否清楚，有无歧义、冗余或晦涩 |
| 用词精准度 | 名词动词是否具体，形容词是否必要 |
| 节奏感 | 句式是否单一，长短句是否搭配 |
| AI 腔检测 | 是否有不自然的模板化表达、过度对仗、空洞排比 |
| 事实准确性 | 事实、数字、专名是否准确（标注待核验） |

### 修改建议
- 列出本段最需要修改的 1-3 个点
- 每个修改点说明：问题是什么、为什么改、改成什么方向

### 修订文本
- 直接给出修订后的完整段落
- 必须是可以直接替换原文的成品
- 保留原文中有效的事实、语气和关键信息
- 不改变用户的核心立场和事实边界

## 诊断等级

每段给出一个总体等级：

| 等级 | 含义 | 行动 |
| --- | --- | --- |
| ✅ 可用 | 内容充实、表达清楚、逻辑连贯 | 无需修改，可保留 |
| ⚠️ 小改 | 有局部问题但不影响理解 | 给出微调建议和修订文本 |
| 🔧 重写 | 有结构性问题，需要重写本段 | 给出重写方向和完整修订文本 |
| ❌ 删除 | 内容空洞、重复或离题 | 建议删除或合并到其他段落 |

## 全文汇总

逐段审阅完成后，给出全文汇总：

### 1. 总体判断
- 全文最突出的 1-2 个优点
- 全文最需要优先解决的 1-2 个问题

### 2. 修改优先级
- 按影响程度排序，列出最值得修改的段落
- 每条标注：段落编号、问题类型、修改方向

### 3. 一致性检查
- 术语一致性：同一概念是否全文统一
- 语气一致性：全文语气是否统一
- 逻辑一致性：前后论点是否矛盾
- 数字一致性：同一数据是否全文一致

### 4. 单一下一步
- 推荐用户最值得先做的一件事

## 修订写作标准

- 修订文本要融入上下文，不能脱离前后段独立存在。
- 保留原文锚点（段落编号、关键句），方便用户定位和对比。
- 不为统一风格而静默改写范围外内容。
- 用户拒绝改动时，以保留原文为恢复依据。
- 修改范围含糊时，先声明最小范围，提供一段标为"预览"的改写，只问一个确认问题。

## AI 腔检测清单

以下模式出现时标注为 AI 腔并建议修改：

- 过度对仗排比（"不仅……更……""既……又……还……"密集出现）
- 空洞总结句（"总之""综上所述""由此可见"频繁出现）
- 模板化过渡（"值得注意的是""需要指出的是"频繁出现）
- 无信息增量段落（整段都在说"很重要"但没说为什么）
- 过度使用形容词而缺少具体名词和动词
- 不自然的正式化（把口语能说清楚的事写成学术腔）

## 输出格式示例

```
## 逐段修改反馈

### 第1段
**原文摘要**：[一句话概括]
**诊断**：⚠️ 小改
- 内容充实度：正常
- 表达清晰度：需改进（第2句主语缺失）
- AI 腔检测：发现模板化过渡"值得注意的是"

**修改建议**：
1. 补充第2句主语，明确动作执行者
2. 删除"值得注意的是"，直接陈述

**修订文本**：
> [修订后的完整段落]

---

### 第2段
...

## 全文汇总
### 总体判断
- 优点：[1-2条]
- 问题：[1-2条]

### 修改优先级
1. 第3段：[问题] → [方向]
2. 第7段：[问题] → [方向]

### 一致性检查
- 术语：[结果]
- 语气：[结果]

### 单一下一步
[一个可直接执行的动作]
```

## 禁止

- 只说"这里需要改"但不给修订文本。
- 越过审阅范围改写全文。
- 改变用户的核心立场、事实边界或作者声音。
- 把逐段反馈变成全文重写。
