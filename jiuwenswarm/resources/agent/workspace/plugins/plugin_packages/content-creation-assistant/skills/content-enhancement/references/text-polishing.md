# Text Polishing / 文本润色

在不改变结构和事实的前提下提升语言质量的工作流程。

## 核心原则

**只改语言，不改意思**：润色提升表达质量，不改变事实、立场、结构或作者声音。保留原文核心信息，优化表达方式。

## 润色分级

| 等级 | 适用场景 | 操作范围 |
| --- | --- | --- |
| 轻度润色 | 正文基本可用，只需微调 | 用词替换、标点修正、个别句式调整 |
| 中度改写 | 有表达问题但不需重构 | 句式重组、冗余删除、过渡优化、语气统一 |
| 深度打磨 | 表达问题较多，需要逐句优化 | 逐句重写、节奏重构、表现力增强、全面去 AI 腔 |

用户未指定等级时，默认从轻度开始，发现需要更深处理时升级并说明理由。

## 润色维度

### 1. 用词优化
- 空泛形容词 → 具体名词和动词（"很好的效果" → "转化率提升 23%"）
- 重复用词 → 同义替换或句式变换
- 模糊量词 → 精确数字（"很多用户" → "1.2 万活跃用户"）
- 口语化表达 → 书面化（视文体而定，不过度正式化）
- 生僻术语 → 通俗解释或替换（视目标读者而定）

### 2. 句式节奏
- 长短句搭配：避免全长句或全短句，形成节奏变化
- 主动被动转换：优先主动语态，被动用于强调承受者时
- 倒装强调：关键信息前置或后置以制造强调
- 避免句式单一：不连续使用相同句式结构
- 段落节奏：每段有信息密度变化，不均匀堆砌

### 3. 去冗精简
- 删除废话：无信息增量的句子直接删除
- 合并重复：同一信息多次出现的合并为一次
- 压缩冗长：能用短句说清的不用长句
- 删除套话："众所周知""不言而喻"等直接删除
- 删除过度修饰：不影响意思的形容词和副词精简

### 4. 语气统一
- 全文语气与目标读者匹配
- 不中途从口语变学术，或从学术变口语
- 保持作者声音一致，不引入突兀的语气转换
- 不同文体的语气基准：
  - 议论文：理性、有力、有立场
  - 叙事文：生动、有画面感、有情感
  - 教程：清晰、简洁、可操作
  - 营销文案：有共鸣、有说服力、有行动号召
  - 学术论文：严谨、客观、规范

### 5. 去 AI 腔
以下模式出现时标注并修改：

| AI 腔模式 | 示例 | 修改方向 |
| --- | --- | --- |
| 过度对仗排比 | "不仅……更……""既……又……还……"密集 | 拆散排比，用自然句式 |
| 空洞总结句 | "总之""综上所述""由此可见"频繁 | 删除或替换为具体总结 |
| 模板化过渡 | "值得注意的是""需要指出的是" | 直接陈述，不用过渡套话 |
| 无信息增量段 | 整段说"很重要"但没说为什么 | 补充具体原因或删除 |
| 过度形容词 | 堆砌形容词缺少具体名词动词 | 用具体名词动词替换 |
| 不自然正式化 | 把口语能说清的写成学术腔 | 用自然表达替换 |

### 6. 表现力增强
- 画面感：用具体场景和细节代替抽象概述
- 节奏感：用句式长短变化制造阅读节奏
- 情感张力：用具体细节和动词传达情感，不用形容词直说
- 对比张力：用对比或反差制造认知冲击
- 具体化：用具体案例、数据、场景代替泛泛而谈

## 润色流程

### 1. 润色诊断
- 快速扫描全文，识别最突出的 1-2 个语言问题
- 确定润色等级（轻度/中度/深度）
- 列出需要重点处理的段落

### 2. 润色执行
- 逐段给出润色后的文本
- 每段标注主要变更类型（用词/句式/去冗/语气/去AI腔/表现力）
- 保留原文锚点，方便用户对比

### 3. 变更说明
- 全文汇总：主要变更类型和数量
- 保留原文中有效的事实、语气和关键信息
- 不改变用户的核心立场和事实边界

## 输出格式

```
## 润色诊断
- 润色等级：[轻度/中度/深度]
- 核心问题：[1-2 个最突出的语言问题]
- 重点段落：[需要重点处理的段落编号]

## 逐段润色

### 第1段
**变更类型**：用词优化、去冗
**润色后**：
> [润色后的完整段落]

### 第2段
...

## 变更汇总
| 变更类型 | 涉及段落 | 主要变更 |
| --- | --- | --- |
| 用词优化 | 第1、3段 | [说明] |
| 去冗精简 | 第2、5段 | [说明] |
| 去 AI 腔 | 第4段 | [说明] |
```

## 禁止

- 改变事实、数据、立场或作者声音。
- 把润色变成全文重写或结构调整。
- 不给变更说明，只给润色后文本。
- 过度润色：把自然的口语化表达强行改成书面腔。
- 编造原文中没有的具体数据来替换模糊量词（标注待核验）。
