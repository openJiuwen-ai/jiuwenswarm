# Health Life Advisor / 健康生活顾问

依托现代健康科学体系的健康生活顾问，提供营养膳食、作息睡眠、情绪调养咨询，生成个性化、可迭代的长期健康生活规划方案。

## 核心能力

- **营养膳食咨询**：多轮采集饮食信息，对照《中国居民膳食指南》评估膳食结构，生成个性化饮食方案与参考食谱，提供食材科普与误区纠正
- **作息睡眠管理**：评估睡眠现状，提供睡眠卫生指导与分阶段作息重建方案，区分普通睡眠困扰与病理失眠
- **情绪调养与压力调节**：疏导日常压力焦虑，提供可落地减压方法，识别高危信号触发安全提示
- **长期个性化健康规划**：生成 2-4 周可落地生活方案，拆解为每日/每周小动作，支持迭代调整与季节适配
- **本地化健康生活规划**：结合附近运动场所、路线、健康餐饮、菜市场、超市、药店/医院等现实资源，把地图结果转成可执行行动
- **健康科普与误区甄别**：甄别伪养生说法，输出循证科普，提供适合普通人群的运动建议

## 能力构成

- **Persona**：定义健康生活顾问角色、工作方式和安全边界
- **Skill**：提供健康评估、方案生成、复盘迭代、本地地图规划规则
- **Tool**：`health_profile_tool`，用于健康档案、方案和执行记录管理
- **Rail**：`safety_guard_rail`，用于高危健康/心理信号拦截
- **MCP**：`amap`，用于周边地点、路线和本地生活资源查询

## 安全边界

- 禁止疾病诊断、症状判病、开药方、用药指导
- 不替代营养师、医生、心理咨询师
- 检测高危关键词（胸痛、持续失眠、躯体疼痛、自杀/自伤想法）触发安全提示
- 不推荐保健品，不做疗效承诺
- 使用地图能力前先确认用户同意，只要求粗粒度位置，不保存精确住址

## 使用方式

在 JiuwenSwarm 专家中心打开该专家，按引导对话。首次对话会逐步了解你的健康状况和目标，随后生成个性化方案并支持持续迭代。
