# 成本架构与 FinOps

## 核心原则

架构决策天然带成本。每个技术选型、每个扩展策略、每个冗余部署都在花钱。成本应成为架构评审的一等维度，而非事后优化。

## 容量成本建模

### 成本分解

```
总成本 = 计算成本 + 存储成本 + 网络成本 + 数据库成本 + 中间件成本 + 人力运维成本
```

| 成本类型 | 计费模式 | 优化杠杆 |
|---------|---------|---------|
| 计算（VM/容器） | 按实例规格×时长 | Spot 实例 + HPA 自动伸缩 |
| 存储（对象/块） | 按容量×时长 + 请求次数 | 冷热分层 + 生命周期策略 |
| 网络（出站流量） | 按传输量 | CDN 缓存 + 同区域部署 |
| 数据库（RDB/NoSQL） | 按规格 + 存储 + I/O | 读写分离 + Serverless + 连接池 |
| 消息队列 | 按消息数 + 存储 | 批量发送 + 消息压缩 |
| 缓存（Redis） | 按规格 + 存储 | 合理 TTL + 淘汰策略 |

### 成本估算公式

```
月度计算成本 = Σ(实例规格单价 × 实例数 × 730 小时 × 利用率系数)
月度存储成本 = Σ(存储单价 × 容量 GB × 730 小时 / 730) + 请求次数 × 请求单价
月度网络成本 = 出站流量 GB × 单价
月度数据库成本 = 实例单价 × 730 + 存储 + I/O 次数 × 单价
```

### 成本与架构模式的关系

| 架构决策 | 成本影响 | 隐性成本 |
|---------|---------|---------|
| 微服务拆分 | 计算成本 ↑（多实例冗余） | 运维成本 ↑（监控/日志/链路） |
| 多区域部署 | 计算成本 ×N | 跨区域流量成本 ↑ |
| 事件驱动 | 消息队列成本 ↑ | 事件存储成本 ↑ |
| Serverless | 按调用计费 | 冷启动延迟 + 高频调用成本失控 |
| 读写分离 | 数据库成本 ↑ | 数据同步成本 ↑ |

## 闲置资源识别

### 常见闲置资源

| 资源类型 | 闲置信号 | 发现方法 |
|---------|---------|---------|
| 计算实例 | CPU 利用率 < 10% 持续 7 天 | CloudWatch / Prometheus 指标 |
| 数据库实例 | 连接数 < 10 持续 7 天 | 数据库监控 |
| 存储卷 | 未挂载的 EBS / 磁盘 | 云平台资源清单 |
| 弹性 IP | 未关联实例 | 云平台资源清单 |
| 负载均衡器 | 后端实例为 0 | 云平台资源清单 |
| 快照/备份 | 超过保留期 | 生命周期策略检查 |
| 消息队列 | 队列积压 = 0 持续 30 天 | 队列监控 |

### 闲置资源清理流程

```
1. 资源清单导出（云平台 API / Terraform state）
2. 利用率分析（过去 7/30 天指标）
3. 闲置标记（< 10% 利用率 = 候选清理）
4. 人工确认（避免误删预发/灾备资源）
5. 清理执行 + 成本节省记录
6. 定期（每月）重复
```

## 按量计费陷阱

### Serverless 成本失控

```
陷阱：按调用次数计费，高频调用时成本可能超过固定实例

判断公式：
  Serverless 月成本 = 调用次数 × 单价 + 计算时间 × 计算单价
  固定实例月成本 = 实例规格单价 × 730

  当 Serverless 成本 > 固定实例成本 × 0.7 → 考虑迁移到固定实例
```

### 数据传输成本

```
陷阱：跨区域/跨可用区数据传输收费

常见场景：
- 多区域数据库复制 → 跨区域流量
- 跨可用区负载均衡 → 跨 AZ 流量
- CDN 回源 → 源站出站流量

优化：
- 同区域部署数据库和应用
- CDN 缓存命中率 > 95%
- 批量传输替代高频小包
```

### 存储成本陷阱

```
陷阱：热存储存冷数据

常见场景：
- 日志全量存 SSD（应冷归档）
- 测试数据存高性能存储（应降级）
- 快照不设生命周期（无限累积）

优化：
- 日志 → 30 天后自动迁移到归档存储
- 快照 → 设置保留策略（如保留最近 7 天 + 每月 1 个）
- 冷数据 → 对象存储 + 生命周期策略
```

## 成本优化策略

| 策略 | 预期节省 | 实施难度 | 风险 |
|------|---------|---------|------|
| Spot 实例（无状态服务） | 60-70% | 中 | 中断风险 |
| HPA + VPA 自动伸缩 | 30-50% | 中 | 无 |
| 存储冷热分层 | 40-60% | 低 | 无 |
| CDN 缓存 | 20-40%（网络） | 低 | 缓存一致性 |
| 读写分离 | 30-50%（数据库） | 中 | 数据延迟 |
| 闲置资源清理 | 10-20% | 低 | 误删风险 |
| 预留实例/承诺折扣 | 30-50% | 低 | 锁定 |

## 成本评审清单

```
✅ 架构方案含成本预估（月度/年度）
✅ 计算资源有自动伸缩策略
✅ 存储有生命周期策略（冷热分层）
✅ 非生产环境有自动缩容/关停
✅ Spot 实例用于可中断工作负载
✅ 成本告警和预算监控就位
✅ 定期审查闲置资源（每月）
✅ Serverless 有成本上限保护
```
