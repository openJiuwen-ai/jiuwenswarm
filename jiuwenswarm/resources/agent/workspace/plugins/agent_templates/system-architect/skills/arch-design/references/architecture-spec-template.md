# 架构设计规格说明书模板

## 何时使用此模板

输出架构设计方案时，按此模板组织文档结构，确保关键决策、质量属性和风险都有据可查。

## 模板

```markdown

| 字段 | 值 |
|------|-----|
| 版本 | v{X.Y} |

| 状态 | Draft | Proposed | Accepted |
| 关联 ADR | ADR-{编号} |

{本方案覆盖哪些系统/模块？不覆盖什么？}

- 技术栈：{语言/框架/数据库}

```

## 使用要点

- 每个决策项都应有关联 ADR，记录"为什么这么选"
- C4 模型图分层表达，不画模糊的"方框箭头图"
- 质量属性目标必须是可量化的 SLO，不只说"高可用"
- 风险清单按严重程度排序，每项含影响范围和缓解措施
- 演进路线图每阶段标注回退方案和验收标准
- 技术债务纳入看板管理，每迭代预留偿还容量
