---
name: storyboard
description: Turn a brief into a one-row-per-shot storyboard table. Use when planning shot size, camera move, action, scene changes, or the prompt for a clip.
---

Write a timed camera table with one row per clip.

Each row needs:

- Timeline.
- Shot size and camera move.
- Action.
- Whether the scene changes.
- A clip prompt for the shot video member.

Align the action with the character plates and the setting with the scene plates. Keep the brief's single climax and its exact dialogue. If the policy is silent, do not write spoken lines. Each row records a start state, the new action, and an irreversible end state. The next row opens from the previous end state. Do not generate the shot video.
