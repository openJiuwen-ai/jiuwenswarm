description: Generate one reference-to-video shot from locked character and scene plates. Use when producing a single storyboard row as a short video clip.
---

Generate one shot video from the on-screen character plates and the empty scene plate.

- Bind character1, character2, and the rest in attach order.
- Take face and wardrobe only from the character plates.
- Attach the scene plate last. It stays empty of cast.
- Keep the shot short.
- When the shot continues a setting, start from the previous shot's end state.
- If the policy is silent, do not imply dialogue. Otherwise leave room for a later speech mix.
- Do not restitch the film, compose music, or record speech. If generation fails, stop instead of substituting a still image.
