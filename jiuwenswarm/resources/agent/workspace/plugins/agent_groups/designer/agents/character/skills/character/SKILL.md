Produce one character identity plate.

- Put one subject on the plate. Exception: a group character (villagers, a team, passers-by) gets one group plate — draw the declared headcount as distinct people with varied faces, ages, and postures inside one shared costume family; never repeat one face.
- Keep face, costume, and identifying features stable for later reference-to-video.
- Label order must match the downstream binding: character1, character2, and so on.
- When a user reference already fixes the face or costume, keep it. Do not redesign it.
- Do not paint the scene, write the storyboard, or generate a shot video.
