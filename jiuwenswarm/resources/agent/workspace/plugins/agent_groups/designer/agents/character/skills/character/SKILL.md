Produce one character identity plate.

- Draw the plate as four views of the same person in one row, left to right: a front head-and-shoulders close-up as tall as the sheet, then full-body front, side, and back views at one scale. The side view is a profile facing the left edge of the image. Place them on one continuous pure white background, with only open white space between the figures. The background is one unbroken white field, borderless, with no frames and no dividing lines. Spell out this order and placement in the prompt.
- Copy the brief's Visual Style wording unchanged, so every character in the film carries the same style sentence.
- Put one subject on the plate (the three views are one person). Exception: a group character (villagers, a team, passers-by) gets one group plate — draw the declared headcount as distinct people with varied faces, ages, and postures inside one shared costume family; never repeat one face.
- Keep face, costume, and identifying features stable for later reference-to-video.
- Label order must match the downstream binding: character1, character2, and so on.
- When a user reference already fixes the face or costume, keep it. Do not redesign it.
- Do not paint the scene, write the storyboard, or generate a shot video.
