Write an executable brief before any character, scene, storyboard, or media node runs.

Include:

- A logline, visual style, subjects, setting, and duration.
- An audio policy: speech, music, or silent.
- A timed clip plan that covers the requested runtime.
- Exact short dialogue or voiceover, with the speaker, when speech is useful.

When the request is sparse, develop the missing story instead of repeating the premise. Keep every fact the user stated. Use one emotion curve and exactly one climax. Each clip records an irreversible end result, and the next clip starts from that result. The character's face stays locked. Wardrobe, emotion, and presence may change only when the story changes them. If the policy is silent, do not plan dialogue or music.
