# TE-Ideation（构思模块）

## 职责

对应 FARS 的 Ideation 模块：文献调研 → 研究问题 → 可验证假设。围绕
**掩码扩散语言模型（MDLM）的 token 编辑**，并从视觉-语言-动作（VLA）策略中
借入两个机制：实时分块（Real-Time Chunking, RTC）与时间集成（Temporal
Ensembling, ACT）。

## 输入

- `{PROJECT_DIR}/references/` 下的背景材料（若有）
- 工作目录 `{PROJECT_DIR}`

## 流程

1. **文献调研**（`web_search` / `web_fetch`）。必须覆盖四类：
   - 离散/掩码扩散：D3PM、SEDD、MDLM、LLaDA、Dream
   - 推理期解码：Fast-dLLM（置信度阈值并行解码）、ReMDM（重掩码采样器）、
     Plan-for-Speed（块大小对精度/迭代数的影响）
   - VLA 动作分块：ACT（时间集成）、RTC（软掩码 + 指数衰减 + 引导裁剪）、π0
   - **引用必须逐条核对真实存在**（标题、作者、年份、arXiv 号）。禁止凭记忆写
     引用；查不到就不要引。
2. **定位最近邻工作**：明确写出「谁最接近我们」以及「我们不能再推导什么」。
   本主题中 ReMDM 是最接近的先前工作，其 ReMDM-conf 规则不得被重新推导当作
   自己的贡献。
3. **提出研究问题**：写成一句话，且必须是可被单一实验否证的。
4. **提出 8-13 条假设 H1..Hn**，每条给出「实验编号 + 被否证的条件」两列。
   假设必须包含**至少一条自我否证**的假设（即：如果结果为某值，则整个立论
   作废）。只写「预期会成功」的假设视为不合格。
5. **写出「什么情况下我们会放弃该框架」**，具体到阈值。

## 输出（写入 {PROJECT_DIR}/outputs/）

- `stage1-ideation.md`：文献笔记、机制映射表、研究问题、假设表、放弃条件
- `stage-1-done.txt`：最后写入，内容为 `DONE`

## 质量门

- 每条引用可追溯到具体来源；无法核实的引用一律删除
- 假设表中每条假设的被否证条件是**数值化的**
- 明确写出「若 H1 被否证则本课题无标的」这类整体性风险
