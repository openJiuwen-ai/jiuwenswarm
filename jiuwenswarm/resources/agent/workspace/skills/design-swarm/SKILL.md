# design-swarm · 设计技术兵

## 核心职责

| 职责 | 描述 |
|------|------|
| 3D渲染 | 户型3D效果图+全景图 |
| 布线设计 | 智能布线图+回路分配 |
| 点位规划 | 设备点位图+房间标注 |
| 产品图册 | PDF图册解析+变体设计 |
| 图标制作 | SVG图标+品牌VI |

## 交付物标准

| 交付物 | 格式 | 验收标准 |
|--------|------|----------|
| 3D效果图 | PNG | 1080p+视角全面 |
| 智能布线图 | HTML | 强弱电分离+标注完整 |
| 设备点位图 | HTML | 图标统一+房间标注 |
| SVG图标 | SVG | 风格统一+可缩放 |

## 工具矩阵

| 工具 | 功能 |
|------|------|
| smart-home-wiring | 布线图生成 |
| lobster-pdf-vision | PDF图册解析 |
| smart-home-icons | SVG图标集 |
| shuangge-brand-visual | 品牌视觉生成 |
| ip-character-design | IP角色设计/手办/毛绒/表情包/周边 |

## 质检清单

- [ ] 设备位置与点位图一致

- [ ] 视角覆盖（主要房间全覆盖）
- [ ] 图标风格统一
