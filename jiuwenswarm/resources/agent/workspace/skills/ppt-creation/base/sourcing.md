# 内容、图片与引用

## 事实优先级

1. 用户提供的文件、数据、图表和明确陈述；
2. 用户指定的权威来源；
3. 官方文档、论文原文、标准和一手数据；
4. 可靠的二手研究与新闻；
5. 仅用于气氛或场景的视觉素材。

用户要求只基于内部材料时，不联网补充外部事实。

## 数据与结论

- 记录数字、日期、定义和结论的来源。
- 不把来源的推测写成事实，不把相关性写成因果。
- 图表旁或页脚附近放简洁来源；详细链接可写入备注或交付清单。
- 对存在口径、样本、时间范围或可比性限制的数据，保留必要边界说明。

## 论文视觉

- 页面在解释一篇具体论文的机制或结果时，可优先考虑论文原图。
- 原图只有在可读、直接支持核心信息且版面允许时才使用；否则自绘简化关系图并注明“根据论文整理”。
- 原图保持比例、颜色、标签和内容，不为了统一风格改造图内信息。
- 页面或备注中标明论文题目、作者/机构、年份或链接中的必要部分。

## 网络图片

- 真实人物、地点、产品、事件和新闻场景优先使用可验证的真实图片。
- 保存来源页、作者/机构、许可和下载时间。
- 明确需要署名的图片，在使用该图片的页面内提供简洁署名。
- 许可未知、禁止演绎或不适合商业使用时不要自动采用。

## AI 图片

- 仅在用户允许且真实素材、自绘或抽象几何无法满足表达时考虑。
- 不用 AI 图片伪装真实产品、人物、实验结果、论文图或新闻现场。
- 保持全 deck 的生成风格一致，并在交付时说明使用情况。

## 占位与回退

视觉素材获取失败不应导致编造。按页面设计选择：

- 改为原生自绘；
- 改为文字或数据表达；
- 使用清晰命名的占位；
- 向用户索要素材；
- 拆分或调整页面论点。

最终交付列出仍存在的占位和回退方案。
