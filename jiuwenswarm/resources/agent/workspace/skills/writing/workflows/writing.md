# Evidence-first collaborative workflow

1. Inspect immutable inputs, validate evidence readiness, and build a versioned paper contract.
2. Plan and verify deterministic visual assets, preferring a single-experiment, semantically auditable Module-3 figure before deterministic redrawing; then derive chapter contracts from the shared contract.
3. Specialized writers produce sections plus replayable handoffs; an integration editor produces the only manuscript draft.
4. Claim, literature/novelty, argument, and final visual reviewers report scoped issues. A coordinator routes bounded revision and the editor reintegrates.
5. Generate title and abstract from the reviewed integrated manuscript, then run final-paper review.
6. Render controlled TeX, compile with Tectonic, and validate the PDF. Short horizontal figures are tightly bounded; wide result tables retain a readable type floor and are vertically paneled rather than scaled down.

All terminal exits use a stable verdict. A malformed or truncated long JSON response receives a bounded compact retry before section-level repair; explicit runtime retry limits are never overridden.
