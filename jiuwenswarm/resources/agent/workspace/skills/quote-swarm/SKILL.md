## 🔄 五步闭环流程

### Phase 1：输入源确认

**输入类型：**

| 类型 | 工具 | 输出 | 紧急度 |
|------|------|------|-------|
| DXF/DWG | smart-home-dxf-pro | 户型数据 | 常规 |
| JPG/PNG | smart-home-dxf-pro | 图像识别 | 常规 |
| 360全景 | panorama-reader | 照明方案 | 常规 |
| PDF图册 | lobster-pdf-vision | 产品数据 | 按需 |

---

### Phase 2：户型解析

**解析命令：**

```bash
# DXF解析
@smart-home-dxf-pro
  输入：[DXF文件路径]
  输出：房间信息+墙体数据+设备块

# 全景识图
@smart-home-panorama-reader
  输入：[360全景链接]
  输出：灯具布局+照明方案

# AI验图
@siliconflow
  模型：Qwen3-VL-32B
  输入：[渲染PNG]
  输出：设备数量+型号确认
```

---

### Phase 3：方案设计

**设计命令：**

```bash
# 点位规划
@smart-home-floorplan
  输入：房间信息+设备清单
  输出：2D点位规划图

# 布线设计
@smart-home-wiring
  输入：点位图+设备清单
  输出：智能布线图+回路分配
```

---

### Phase 4：报价生成

**报价命令：**

```bash
# 爽哥智能报价
@shuangge-quote
  输入：设备清单+客户信息
  参数：
    customerName: [客户名]
    area: [面积]
    houseType: [户型]
    productQuantities: {设备ID: 数量}
  输出：HTML报价单
```

**铁律**：只改数量，其他字段锁死！

---
