# 编辑既有 PPTX

## 原则

用户提供的 PPTX 是本任务的结构事实来源。保留其 Master、Layout、主题、页面尺寸、备注、批注和已确认内容，除非用户明确要求改变。

不要为了使用新建 deck 的组件系统而把原文件全部重建成固定组件页。

## 路径选择

- 只改少量文字、图片、页序或页面：优先使用现有 XML 编辑流程，见 [../editing.md](../editing.md)。
- 需要新增少量本模板内容页：在与原文件一致的尺寸和模板外壳下生成新页，再使用合并流程。
- 需要全面重设计：先提取原文件结构和内容，生成 preservation contract，再按用户确认的自由度重构。

## 基本步骤

1. 生成缩略图并提取文本；
2. 检查页面尺寸、Master/Layout、主题、媒体、图表、备注和批注；
3. 建立逐页修改映射；
4. 先完成页面增删、复制和调序等结构操作；
5. 再编辑内容；
6. 清理、打包并验证；
7. FULL 模式下对修改页和相邻页做渲染复核。

## 设计边界

- 原 deck 已有成熟视觉语言时，优先延续；不要强行叠加新组件风格。
- 用户要求转为本模板时，以 `../base/template-contract.md` 为目标，但先确认允许改变的结构范围。
- 新增内容页可以自由设计，但必须与原 deck 的跨页系统兼容。
