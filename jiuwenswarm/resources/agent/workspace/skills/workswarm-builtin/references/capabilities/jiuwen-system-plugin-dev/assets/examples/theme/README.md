# 主题背景

为 WorkSwarm 提供动态背景、界面配色与启动开场动画，内置 4 套主题，也可导入自己的主题包。

## 功能

- 应用背景：在工作界面最底层显示图片、视频或动态页面，可调背景暗化、模糊与面板不透明度；减少动态时显示静态图。
- 界面配色：按主题设置强调色与半透明面板。
- 开场动画：应用启动时播放当前主题的开场，可设开场音乐与音量，播放时机可选每次启动、每天首次或仅手动预览，长按空格跳过。
- 内置主题：科研终端、晨雾蓝图、流光极昼、蜂巢协同。
- 主题管理：导入符合主题接口 v1（`theme.json`）的主题包（ZIP 或文件夹），导出备份并从备份恢复。

## 生效机制

插件运行在 Gateway 侧（`package.domain: gateway`），通过宿主的应用级界面能力生效：

1. 背景：宿主挂载 `application.background` 后触发 `ui.ready`，插件用 `ops.ui.render` 渲染媒体容器，素材地址由 `ops.ui.asset_url` 生成。
2. 配色：插件调用 `ops.appearance.apply` 提交强调色与半透明模式，宿主据此派生界面颜色；恢复原版界面时撤销。
3. 开场：宿主启动门控依次向开场提供者发送 `application.splash` 的 `ui.ready`，插件按播放时机决定播放或略过；播放完成、跳过或超时后收到 `ui.closed`。设置页的“预览开场”调用 `ops.splash.preview`。
4. 设置：设置导航中的“主题背景”由 `application.settings` 声明，交互经 `ui.click` 与 `ui.change` 处理。偏好保存在 `ops.store`，导入的主题保存在 `ops.data.root()` 指向的插件数据目录，备份经 `ops.ui.download` 下载。
5. 浏览器连接断开时（`gateway.disconnect`）清理该连接的界面状态。

## 优势

- 不改动宿主页面：背景与开场运行在沙箱容器中，位置、时机、超时与跳过由宿主控制，宿主升级不会被插件样式破坏。
- 文字始终清晰：强调色由宿主按对比度派生，半透明只在有背景时生效，弹出层与文字保持可读。
- 主页不会先于开场露出，刷新或断线重连不会重复播放开场。
- 适合希望统一团队视觉、或在演示与展示场景中使用定制开场的用户。
