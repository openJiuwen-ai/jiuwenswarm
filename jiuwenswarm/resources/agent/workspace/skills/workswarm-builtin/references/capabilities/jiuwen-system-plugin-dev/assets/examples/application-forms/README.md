# 应用形态

将 JiuwenClaw 工作台切换为轻巧的桌面形态，在处理其他工作时查看会话进展、继续对话。

## 功能

- **蜜蜂桌宠**：内置动态蜜蜂，显示思考、工具调用、回复和完成等状态；单击查看会话，点击「＋」开始新会话，拖动调整位置。
- **桌面会话**：查看当前一轮消息与完整回复，发送消息、停止执行、选择模型；需要完整操作时返回工作台。
- **自定义形态**：导入包含界面、交互和素材的资源包，各资源独立保存设置。胶囊卡片是可选导入资源，支持深色与浅色，未包含在插件 ZIP 中。
- **切换动效与音效**：蜜蜂与工作台之间提供双向过渡，搭配可关闭、调节和试听的「咻」「轻弹」音效。

## 生效机制

启用插件后，`ui.ready` 登记可用形态并加载设置；用户通过应用的形态切换入口进入桌面窗口。导入资源和保存设置不会触发形态切换。

`ui.change` 处理资源导入及偏好修改，`ui.click` 处理资源移除与图片重置，`ui.press_enter` 保存资源文本设置。会话状态和操作连接到应用已有会话；双击蜜蜂或选择「打开工作台」可回到完整界面。

桌面悬浮与切换动效需要支持应用形态和窗口过渡协议的 JiuwenClaw 桌面客户端。工具授权、待确认问题及完整历史仍在工作台处理。

## 优势

查看进度和回复消息只需展开小窗，方便与其他桌面工作并行。可以使用内置蜜蜂，也可以通过导入资源选择适合自己的界面；资源设置与音效偏好在重启后保留。
