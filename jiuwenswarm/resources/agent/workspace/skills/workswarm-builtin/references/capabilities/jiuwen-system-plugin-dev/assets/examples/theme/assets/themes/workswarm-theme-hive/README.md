# 蜂巢协同（主题包）

openJiuwen 专属的 3D 主题，需要配合「主题接口」扩展使用。形象取自 JiuwenSwarm 的绒毛小蜜蜂，概念取自“蜂群协同”：一只小蜜蜂勾出六边形网络标志，蜂巢生长、蜂群涌出并彼此连线，最后列成阵列进入工作台。

- **开场动画**（`boot/`，约 7 秒，黑金色调）：
  1. 小蜜蜂拖着金色光迹飞入。
  2. 光迹勾出六边形网络标志，顶点逐个亮起。
  3. 蜂巢由内向外逐环生长，蜂蜜发光。
  4. 蜂群从巢格中涌出，围绕主角盘旋，并以协作连线相连（底部计数 `AGENTS ONLINE`）。
  5. 蜂群列成六边形阵列，`WorkSwarm` 字标与问候语出现。
  6. 主角飞离，镜头推入中心巢格，暖光收束成工作台的米色。

  开场带 `boot/hive-boot.m4a` 开场音乐，与上述时间点对齐（振翅声、顶点钟音、巢格轻点、蜂群低鸣、字标和弦、推入气流），由 `tools/synth_hive_audio.py` 离线合成。
- **动态背景**（`background/`，浅色）：晨光下缓慢起伏的蜡质蜂巢，部分巢格盛着会发光的蜂蜜；十几只小蜜蜂在上方巡游，彼此之间有淡紫色的协作连线，空中飘着花粉。30 帧上限，窗口隐藏时暂停；减少动态时使用 `poster.jpg`。
- **界面配色**：蜂蜜琥珀强调色 `#b45309`（白字对比度约 5:1），导航选中态带一层暖金色。

## 文件

| 路径 | 说明 |
| --- | --- |
| `lib/hive3d.js` | 共享的 WebGL2 小引擎：分层壳体绒毛的小蜜蜂（眼睛、腮红、微笑、触角、会扇动的半透明翅膀）、带倒角的空心蜡质巢格与蜂蜜、光点、连线、天空、多重采样 + 泛光后期。 |
| `boot/index.html` `boot/scene.js` | 开场页面与时间线；`?t=4.8` 可定格在某一时刻预览。 |
| `background/index.html` `background/scene.js` | 动态背景。 |
| `poster.jpg` / `preview.jpg` | 背景静态图 / 管理页预览图，均由场景实际渲染。 |

没有 WebGL2 时：开场只显示字标与问候语，约 2 秒后进入；背景显示 `poster.jpg`。

开场在 `max_duration_ms`（9.5 秒）内一定结束；系统开启“减少动态效果”时不播放开场。
