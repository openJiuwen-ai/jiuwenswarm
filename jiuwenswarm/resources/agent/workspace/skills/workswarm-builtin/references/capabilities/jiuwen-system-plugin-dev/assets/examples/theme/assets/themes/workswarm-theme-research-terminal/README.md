# 科研终端（主题包）

需要配合「主题接口」扩展（workswarm-theme）使用。

- **开场动画**：内置“科研终端”时间线，约 7 秒：标志启动 → 系统自检 → 档案访问（档案索引逐条检索、解密）→ 研究员身份确认（扫描、比对、结果）→ 访问已授权 → 向上卷起进入工作界面。研究员姓名取自“主题外观”页的“研究员代号”。可按 Esc 跳过。
- **开场音乐**：实时合成的原创声景，没有音频文件——低频和声铺底，配合终端打字、状态提示、阶段切换、身份扫描与授权和弦，退场时淡出。可在“主题外观”页关闭或调整音量（`boot.audio`，见 THEME_API.md 第 5.3 节）。
- **动态背景**：洁净实验室纸色底 + 细网格 + 右下角六边形晶格 + 缓慢漂移的分子网络与周期扫描光带（沙箱 canvas，30 fps，窗口隐藏时暂停）；减少动态时使用 `background/still.svg`。
- **界面配色**：实验室深绿强调色 `#0d8f72`，选中态与滚动条同色系。

视觉方向参考“莱茵生命”式的洁净科研终端、档案访问与身份确认氛围。主题中的标志、图形、文字与动画均为原创绘制，未使用任何游戏的官方素材、标志、角色或名称。

修改开场文字：编辑 `boot/sequence.json`（字段说明见 workswarm-theme/THEME_API.md 第 5.1 节），改完把 `theme.json` 的 `version` 加一，再在管理页点“重新扫描”。
