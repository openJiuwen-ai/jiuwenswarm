# 🔄 五步闭环流程

## 🔄 五步闭环流程

### Phase 1：研究需求确认

**研究类型：**

| 类型 | 触发场景 | 输出 | 紧急度 |
|------|---------|------|-------|
| 个股分析 | 选股/持有个股 | 深度报告 | 常规 |
| 行业研究 | 赛道选择/机会挖掘 | 行业报告 | 常规 |
| 组合诊断 | 定期检视 | 持仓分析 | 每周 |
| 异动监控 | 持仓股突发 | 预警报告 | 🔴紧急 |
| 宏观策略 | 重大政策/事件 | 策略报告 | 按需 |

**需求确认模板：**
```
【投资研究需求】
- 研究对象：[股票代码/名称/行业]
- 研究类型：□ 个股 □ 行业 □ 组合 □ 宏观
- 分析目的：□ 选股 □ 持仓诊断 □ 风险评估
- 持仓情况：□ 无持仓 □ 轻仓 □ 重仓 □ 关注
- 时间要求：□ 常规 □ 加急
```

### Phase 4：投资决策

**决策框架（股票五步法）：**

```
Step 1：宏观分析
├── 政策环境（货币/财政/产业）
├── 经济周期（GDP/CPI/PMI）
└── 资金面（利率/汇率/流动性）

Step 2：行业分析
├── 行业空间（市场规模/增速）
├── 竞争格局（CR3/龙头）
└── 产业链（上游/中游/下游）

Step 3：公司分析
├── 商业模式（卖什么/怎么卖）
├── 核心优势（护城河）
└── 管理团队（能力/诚信）

Step 4：估值分析
├── 绝对估值（DCF/DDM）
├── 相对估值（PE/PB/PS）
└── 估值分位（历史/行业）

Step 5：策略建议
├── 操作建议：□ 买入 □ 持有 □ 减持 □ 卖出
├── 目标价位：¥XX
├── 止损价位：¥XX（-X%）
├── 建议仓位：X%
└── 持有周期：X个月
```

**风险评级：**

| 评级 | 含义 | 适合人群 |
|------|------|---------|
| 🟢 低风险 | 波动<10%，回撤可控 | 保守型 |
| 🟡 中风险 | 波动10-20% | 稳健型 |
| 🟠 较高风险 | 波动20-30% | 积极型 |
| 🔴 高风险 | 波动>30% | 激进型 |

### Phase 5：持仓管理与复盘

**持仓监控：**

```bash
# 持仓诊断
@westock-data
  操作：持仓分析
  持仓：[股票列表]
  诊断维度：
  - 持仓盈亏
  - 仓位占比
  - 相关性风险
  - 集中度风险
  输出：诊断报告 + 调仓建议

# 异动预警
@automation
  名称：持仓异动监控
  触发条件：
  - 持仓股涨跌≥5%
  - 大宗交易
  - 重大公告
  通知方式：微信推送
```

**复盘流程：**

| 周期 | 复盘内容 |
|------|---------|
| 每日 | 持仓变动 + 明日计划 |
| 每周 | 组合表现 + 行业动态 |
| 每月 | 深度复盘 + 策略调整 |
| 每季 | 持仓检视 + 目标复核 |
