## X 平台增长方法论（KOL 实战蒸馏 · 源自 x-mentor-skill, MIT）

> 6 位年入百万美金 X 博主方法论蒸馏。详细文档：`references/x-platform-growth.md`
> 补强 X/Twitter 渠道增长维度（通用 SOP 之外的平台级深度）

### 算法权重（2026.4 开源代码确认）
对话回复 **150x** > 普通回复 **27x** > 主页点击 **24x** > 停留>2min **20x** ≈ 书签 **~20x** > 转发 **2x** > 点赞 **1x**（基准）
- 负面：举报 **-369x** / 屏蔽 **-74x** / 外链降 **30-50%** / >2 hashtag 降 **40%** / 重复内容影子封禁
- **Premium 必要**：TweepCred -128→+100，非 Premium 外链帖中位互动≈0
- 前 15-30min 互动速度定生死（10+→指数扩散，<3→死亡）；每 6h 可见性减半

### 冷启动 SOP（0-1K）
开 Premium + 每天 2-3 条短推 + 每天 5-10 个大号评论区留 200-400 字回复 + DM 3 个同量级互助 + 不急写 Thread；预期日均 5-10 粉 / 4-8 周到 1K

### 选题（4A 矩阵）
一话题×4 角度=无限选题；精益验证飞轮（先 tweet 验证→数据好扩 Thread）；超级碗响应（新模型 0-1h）

### 写作（1/3/1 + Value Equation）
Hook 占 50% 时间写 10-15 版；一句 hook+三句展开+一句过渡；高结果/低 effort；外链放第一条回复

### 账号诊断 6 维
KPI / 内容 ROI / 传播漏斗 / 时间分析 / 品牌叙事 / 行动建议；书签率>点赞率=收藏型账号

### 质量红线
- 发帖必回（对话权重 150x，不回=放弃最大杠杆）
- 主推文不放外链（放第一条回复）
- Thread 8-12 条 sweet spot，超 15 条掉人
- 不买粉/不纯工具合集/不只会翻译

## 中国营销平台模板（小红书·抖音·微信私域 · 蒸馏自 agency-agents-zh, MIT）

> 3 个中国本土营销智能体操作模板蒸馏。详细文档：`references/china-marketing-experts.md`
> 与 X 平台增长维度（上章）互补——本模块覆盖爽哥智能新媒体变现的核心本土阵地

### 小红书运营专家（种草获客）
- **爆款笔记**：标题18-20字(关键词+情绪词) + 竖版3:4封面 + 正文4段(痛点共鸣→引入→体验细节→降期望总结) + 2-3大标签+3-5长尾
- **投放3阶段**：预热(素人KOC铺量)→集中种草(KOL深度测评+头部横评)→长尾(补量+评论维护+搜索锁词)
- **红线**：蒲公英报备、不刷量、真实体验不夸大、医疗金融额外合规
- **指标**：互动率>5%、CPE<¥3、电商引流转化>2%

### 抖音策略师（短视频+直播）
- **脚本模板**：黄金3秒4型(冲突/利益/悬念/共鸣) + 核心内容(痛点→方案→演示→数据) + 收尾钩子；竖屏9:16、真人出镜、字幕必加
- **直播排品**：引流20%/利润50%/形象15%/福利15% + 每15min峰值循环(留人→讲解→逼单→追单)
- **算法权重**：完播率>点赞率>评论率>转发率；前3秒定生死
- **红线**：不引站外、不用绝对化用语、食品药化守广告法
- **指标**：完播率>35%、GPM>¥500、DOU+ ROI>1:3

### 私域流量运营师（企微闭环）
- **SCRM骨架**：渠道活码(包裹卡/直播/门店) + 4维标签(来源/消费力/生命周期/兴趣) + 引流群/VIP群分层
- **社群SOP**：每日6时段排期(早安→种草→互动→秒杀→晒单→晚安) + 新人72h激活
- **生命周期**：新客0-7天激活→成长期→成熟期→沉默90天+唤醒→流失预警人工介入
- **红线**：群发月≤4次、朋友圈日≤1条、价值内容>70%、《个保法》合规
- **指标**：社群7日活跃>35%、新客7日首单>20%、私域LTV为公域3倍+

## 数字产品合规变现子范式（小红书虚拟资料 7 步 SOP · 借 xhs-virtual-product, MIT）

> **来源声明**: 借 `chenjin-cmd/xhs-virtual-product`(MIT) 的「原创合规数字产品 7 步 SOP」方法论, 零克隆(未引其模板原文 / 未整包引入), 仅取范式改写为龙虾军团内容变现纪律。适用于爽哥智能做知识付费 / 虚拟资料变现金, 或任何数字产品内容生产。

### 5 要点（自研吸收）
1. **7 步闭环 SOP + 复盘迭代回环**: 选品 → 对标拆解 → 制作资料 → 上架店铺 → 内容创作 → 复盘优化(迭代回环)。比单次内容生成更完整——内容不是终点, 闭环到复盘才成环。
2. **合规红线置顶**: 只做原创合规内容、点名版权雷区(字体 / 图片 / 模板 / 商用授权 / 平台规则)、规避封号。**每条内容产出前先过合规清单**(咱内容技能原缺这条纪律)。
3. **模板化**: 可填模板复制即填(选品判断表 / 对标拆解 / 商品笔记 / 评论话术 / 合规清单 / 7天计划 / 标题公式), 降低使用门槛, 模板落 `references/` 或 `assets/templates/`。
4. **references 按需加载**: 知识库按任务渐进加载, 不占上下文——强验证咱「渐进式技能加载 / ponytail」思路, 与 DeerFlow progressive loading 同构。
5. **技能即文档**: 纯 Markdown 跨工具可装, 与咱 Skill 体系同构——范式可直接写成 Skill 复用。

### 龙虾落地纪律
- 数字产品 / 内容产出前 **先过合规红线清单**(原创性 / 版权 / 平台规则), 不过不发布
- 内容生产走 **闭环 SOP**, 不单发不复盘
- 模板 / references **渐进加载**, 不一次性塞满上下文

## 短视频编排范式（借鉴 Pixelle-Video, Apache-2.0）

> 来源声明: 借 `AIDC-AI/Pixelle-Video`(Apache-2.0) 的「主题→成品短视频一键编排」产品化思路, 零克隆(未引其代码/未整包引入), 仅取编排范式补强龙虾军团内容生成兵的多平台视频生产能力。评估结论: 锦上添花 P3, 核心能力已由 content-factory/hyperframes/edge_tts/ffmpeg 覆盖, 仅内化其 UI 化编排与多尺寸输出设计。

### 3 要点（自研吸收）
1. **编排 UI 化**: 把分散技能(文案/生图/配音/合成)做成可配置面板, 降低操作门槛——对应咱把 content-factory(文案)+hyperframes(生图)+edge_tts(配音)+ffmpeg(合成) 串成固定 SOP 时, 应做成参数化入口而非每次手写命令。
2. **模板预览 + 多尺寸输出**: 竖(9:16 抖音/视频号)/横(16:9)/方(1:1)一键切换, 正好对齐三平台; 生成前可预览模板样式, 减少返工。
3. **原子能力组合**: 替换生图模型、TTS 引擎的插件式设计——咱生图走 ImageGen/VideoGen 自有通道(零克隆内化), 配音走 edge_tts, 不绑死单一外部依赖(RunningHub/通义千问可能付费, 违反省钱原则)。

### 龙虾落地纪律
- 多平台视频产出走 **参数化 SOP**(尺寸/平台/配音/BGM 预置), 不每次从头拼命令
- 出片前 **模板预览 + 尺寸合规自检**(对齐视频号9:16·抖音9:16·小红书3:4)
- 生图/配音 **原子可替换**, 优先零 credit 自有通道, 外部付费 API 需爽哥确认
- 自动批量生成须过 **anti-ai-slop 质检**, 防 AI slop
