# Cursor 开发知识库 Guide

`docs/ai/` 用于保存 JiuwenSwarm 在 Cursor 中的开发过程、实验、问题、QA、阶段和交接，并由 `.cursor/hooks` 与 `.cursor/rules` 维护。

它与 Downloads 外部长期 KB 相互独立，不能被外部 KB 替代或重定向。

Cursor Agent 启动时读取：

1. `docs/ai/HANDOFF.md`
2. `docs/ai/META/phases.md`
3. `docs/ai/META/preferences.md`
4. 当前主题的 `INDEX.md`、`SUMMARY.md` 和 `QA.md`
