# Name search in My Assets

My Skills, Experts, Expert Teams, Plugins and Connectors match only the name currently displayed on each card. Matching supports substrings, case folding and Unicode compatibility normalization. Hidden translations, package names, asset IDs, descriptions and tags are excluded. When a card displays a fallback name, that visible name is searchable. Changing the interface language follows the name actually rendered on the card. Marketplace search retains its existing Hub behavior.
