# 8 OpenJiuwen 扩展 API 索引

本页用于快速查找 OpenJiuwen 的事件、Ops 方法和 Web Client 前端扩展。它只回答“这项能力做什么、需要什么输入、会返回什么结果”，表格只保留名称、功能定位、输入和输出。

事件何时触发、事件链如何继续、USER Handler、BUILTIN Handler 和 Core Handler 如何分工、默认行为是什么，以及推荐用法和限制，请阅读 [7.【API文档完整版】OpenJiuwen 扩展参考](<7.【API文档完整版】OpenJiuwen 扩展参考.md>)。代码路径、特性文档和维护状态不在本目录索引范围内。

表格中的“待定义”表示规划中的公开契约尚未锁定，不代表可以直接调用。
