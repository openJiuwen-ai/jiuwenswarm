# 设计

> **目标**：帮助你了解 JiuwenSwarm 网页端的「设计」功能：它能做什么、开始前要配置什么、怎么从一句话创意生成一条可视化的创作工作流，以及怎么查看、修改和重跑其中的每一步。
>
> **英文版：** [Design（English）](../en/Design.md)

---

## 1. 设计是什么

### 1.1 一句话介绍

「设计」是 JiuwenSwarm 面向视频、图片等创作场景的工作区。你只需要用一句话描述想做的内容（比如"做一支 30 秒的竖屏短片，讲一只小熊在森林里醒来"），再配上几张参考图，系统会自动把这个想法拆成一张**工作流画布**：

- 先写一份创意简报，再设计角色和场景；
- 然后出分镜表、关键帧图片；
- 再把每一镜生成为视频片段，最后拼成成片。

画布上的每一步都是一个**节点**。你可以看每个节点产出了什么、改它的描述或参考图、只重跑这一个节点，也可以直接告诉助手"把第二镜换成夜景"，由它来改图。

### 1.2 适合做什么

| 场景 | 说明 |
|:---|:---|
| **短视频 / 短片** | 从剧本到分镜到成片一条龙，适合 15 秒到几分钟的叙事短片 |
| **角色与场景设定图** | 只跑到角色设计、场景设计节点，拿一组风格统一的设定图 |
| **分镜与关键帧** | 先出分镜表和关键帧，确认后再决定要不要生成视频 |
| **基于参考素材改编** | 上传自己的图片、视频或音频做参考，让生成结果贴合既有风格 |

目前这一版只支持**基于人物和场景的 AI 视频创作**：先定角色和场景，再按镜头生成画面和视频。其他视频创作场景，以及其他多模态创作任务，会在后续版本逐步支持。

### 1.3 和「对话」有什么不同

| 对比项 | 对话 | 设计 |
|:---|:---|:---|
| 交互方式 | 一问一答，结果在聊天里 | 一张画布，结果挂在节点上 |
| 适合的任务 | 问答、写作、查资料、操作文件 | 多步骤、多素材的视觉创作 |
| 修改方式 | 继续追问 | 改节点、重跑节点、和助手对话改图 |
| 产物 | 文字、文件 | 图片、视频、音频、简报 |

## 2. 开始之前：需要配置什么

设计功能会用到多种模型。请先在左侧导航「更多 → 配置信息」中确认以下配置。

| 模型 | 用途 | 是否必需 | 配置位置 |
|:---|:---|:---|:---|
| **默认模型** | 理解你的需求、写简报、拆分镜、改图 | ✅ 必需 | 配置信息 → 模型配置 |
| **图像生成模型** | 生成角色设定图、场景图、关键帧 | 需要出图时必需 | 配置信息 → 智能体 → 「配置图像生成模型」，并打开**图像生成**开关 |
| **视频生成模型** | 把每一镜生成为视频片段 | 需要出视频时必需 | 配置信息 → 智能体 → 「配置视频生成模型」，并打开**视频生成**开关 |
| **音乐模型** | 给成片配背景音乐 | 可选 | 配置了才会出现音乐节点 |

> 💡 **提示**：视频生成走的是参考图生视频模式，目前已测试支持的视频模型包括 MiniMax H3、Seedance 2.5 系列、Wan 3.0 系列。图像生成目前支持 MiniMax、火山引擎 / BytePlus ModelArk、阿里云百炼（DashScope，如万相系列），以及自建的 vLLM-Omni 服务。因为要带上参考图，**暂时不支持通过 OpenRouter 转发**的图像、视频模型。

> ⚠️ **注意**：如果没有配好，对应节点在执行时会直接失败，并提示类似"Video generation is not configured"的信息。补好配置后，点节点上的「重新生成」即可。

模型配置的字段含义请参考 [配置信息](配置信息.md)。

## 3. 进入设计页面

1. 点击左侧导航的「任务」。
2. 在会话侧栏顶部有一个工作模式下拉菜单（默认显示「工作」），点开后选择**「设计」**。
3. 侧栏会变成设计项目列表，右侧显示设计首页。

切换后，侧栏里会列出你的所有设计项目，支持置顶、重命名、删除，点「新建项目」可以回到设计首页。

## 4. 新建一个设计项目

### 4.1 操作步骤

1. 在设计首页的输入框里，用自然语言描述你想做的东西。
2. （可选）点「+」添加参考素材：最多 **3 张图片、1 个视频、1 段音频**，单个文件不超过 **6MB**。
3. （可选）在右下角选择这次要用的默认模型。
4. 按 Enter 或点发送。页面会提示"正在思考如何搭建设计工作流…"，稍等片刻画布就会出现。

每个设计项目会自动创建**一个项目、一个会话和一张画布**，三者绑在一起。项目名会根据你的描述自动生成，之后可以在侧栏重命名。

### 4.2 描述怎么写效果更好

| 要素 | 说明 | 示例 |
|:---|:---|:---|
| **要做什么** | 短片、设定图、分镜…… | "做一支短片" |
| **讲什么** | 故事梗概、主角、情绪 | "小熊在森林里醒来，发现下雪了" |
| **多长** | 总时长或镜头数 | "30 秒左右""分 6 个镜头" |
| **什么画幅、多清晰** | 横屏 / 竖屏 / 方形，分辨率 | "竖屏 9:16""720p" |
| **什么风格** | 画风、色调、参考作品 | "水彩绘本风，暖色调" |

**示例对比**

| 推荐写法 ✅ | 不够清晰 ❌ |
|:---|:---|
| "做一支 30 秒的竖屏短片，水彩绘本风：小熊在森林里醒来，发现下了第一场雪，开心地跑出去。要 720p。" | "做个小熊的视频" |
| "根据我上传的三张角色图，出 4 张不同场景的设定图，保持同一画风，16:9。" | "出几张图" |

> 💡 **提示**：画幅和分辨率会被系统识别并锁定到所有图片和视频节点上。分辨率支持写 480p、720p、768p、1080p、2K、4K 这类字样；如果超过了所配模型的上限，会自动降到该模型支持的最高一档。

## 5. 认识画布

### 5.1 页面布局

| 区域 | 位置 | 作用 |
|:---|:---|:---|
| 顶部工具栏 | 页面顶部 | 显示项目名；右侧是「执行」「取消」等运行按钮 |
| 左侧栏 | 画布左侧 | 两个标签：「助手」用来对话改图，「素材」查看所有上传和生成的文件 |
| 画布 | 中间 | 节点和连线所在的区域，可拖动、缩放 |
| 底部工具条 | 画布底部居中 | 添加节点、切换鼠标工具、自动布局、打开素材包 |

### 5.2 节点有哪些

按内容类型分，节点有 5 种：**文本**、**表格**、**图片**、**视频**、**音频**。

按在工作流里扮演的角色分，系统自动搭建的工作流通常包含这些节点：

| 节点 | 类型 | 产出 |
|:---|:---|:---|
| **创意简报（Brief）** | 文本 | 一份 Markdown 文档：故事、风格、角色、节奏等总体设定 |
| **角色设定** | 图片 | 每个角色一张设定图 |
| **场景设定** | 图片 | 每个场景一张设定图 |
| **分镜表（Storyboard）** | 表格 | 每一镜的画面、动作、镜头、时长 |
| **关键帧** | 图片 | 每一镜的首帧画面 |
| **片段（Clip）** | 视频 | 每一镜生成的视频片段 |
| **合成** | 视频 | 把所有片段拼成成片 |
| **音乐** | 音频 | 背景音乐（配置了音乐模型才会出现） |

节点右上角会显示执行状态：等待、执行中、已完成、失败。已完成的节点会直接把产物（图片、视频封面、文字摘要）显示在卡片里。

### 5.3 连线是什么意思

连线从左到右，表示"上游节点的产物是下游节点的输入"。例如分镜表连到关键帧，表示关键帧要照着分镜表来画；关键帧连到片段，表示片段要以这张关键帧为首帧。

### 5.4 底部工具条

| 按钮 | 作用 | 快捷键 |
|:---|:---|:---|
| **添加节点** | 往画布中央加一个图片 / 视频 / 音频节点，或导入 ComfyUI 工作流 | — |
| **选择 / 移动** | 点选、框选、拖动节点 | `V`，按住空格可临时平移 |
| **平移画布** | 拖动整张画布 | `H` |
| **自动布局** | 按连线把节点重新排整齐，避免重叠 | — |
| **素材包** | 打开素材面板，可把素材拖到画布上变成节点 | — |

### 5.5 导入 ComfyUI 工作流（进阶）

如果你习惯用 ComfyUI 调参数，可以把它导出的 `.json` 工作流导进来：底部工具条「添加节点」→「ComfyUI」→ 选文件。

需要注意：

- 目前只识别工作流里 **vLLM-Omni 的 Generate Image / Generate Video 节点**，其他节点会跳过并提示；
- 导入的节点会带一个 ComfyUI 标记，它的提示词和采样参数（步数、引导系数、种子等）会**原样发给 vLLM-Omni**，不经过智能体改写；
- 这类节点需要在「配置视频生成模型 / 配置图像生成模型」里填好 vLLM-Omni 的服务地址。

## 6. 执行工作流

### 6.1 运行按钮

顶部右侧的运行按钮会根据当前状态变化：

| 按钮 | 什么时候出现 | 做什么 |
|:---|:---|:---|
| **执行** | 画布刚搭好，还没跑过 | 从头把整条工作流跑完 |
| **执行中…** | 正在运行 | 不可点击，等待完成 |
| **继续** | 之前取消过，或有节点没跑完 | 接着跑剩下的节点 |
| **重试失败节点** | 有节点失败了 | 只重跑失败的那个节点，然后继续往下 |
| **取消** | 运行中 | 停止当前运行，已完成的节点产物保留 |
| **重跑工作流**（下拉菜单里） | 任何时候 | 清掉所有运行状态，从头再来一遍 |

> 💡 **提示**：「执行」会一口气跑完所有能跑的节点，中间不需要你反复点「继续」。执行过程中可以切到其他页面，回来后状态会自动同步。

### 6.2 执行时发生了什么

点「执行」后，后台会按连线顺序一层一层地跑：

1. 先跑没有上游的节点（通常是创意简报）；
2. 上游全部完成的节点进入下一轮，彼此之间并行执行；
3. 每个节点由一个节点智能体负责：读上游产物、组织提示词、调用图像或视频模型、把结果存成文件；
4. 全部跑完后，成片会挂在「合成」节点上。

左侧「助手」标签里会实时显示当前在做什么（思考中、正在调用哪个工具、哪个节点在跑）。

### 6.3 只重跑一个节点

选中某个节点，在工具条里点**「重新生成」**，系统会用当前的上游产物只重跑这一个节点，不影响其他节点。适合"第三镜不满意，只改第三镜"的情况。

### 6.4 新旧版本怎么选

重新生成后，系统会同时保留**原版**和**新内容**：

- 对**创意简报**和**分镜表**这类你可能手动改过的文档，会弹出"选择要保留的版本"对话框，由你决定保留哪一份；
- 对图片、视频等其他节点，运行结束后会自动采用新内容。

你也可以在节点上点「比较版本」随时打开这个对话框。

## 7. 修改与微调

### 7.1 和助手对话改图

左侧「助手」标签就是这个项目的对话框。你可以直接用自然语言提要求，例如：

- "把第二镜改成夜景，加一点雪花"
- "再加一个结尾镜头，小熊回头看镜头"
- "整体换成赛博朋克风格"

**先选中一个节点再发消息**，要求就只针对这个节点；不选节点则针对整张画布。发消息时同样可以附上参考素材（限制同 4.1）。

助手改完后，画布会自动更新，并在对话里告诉你改了什么（已新增节点、已新增连线、已替换输出等）。

### 7.2 手动改节点

点选一个图片、视频或音频节点，节点旁会出现工具条，有三种模式：

| 模式 | 作用 | 可调项 |
|:---|:---|:---|
| **生成** | 让模型生成这个节点的内容 | 画面描述、长宽比、分辨率、时长、是否有声音、生成数量 |
| **上传** | 用你自己的文件作为这个节点的产物 | 浏览文件或直接拖拽进来 |
| **编辑** | 直接改文字（仅文本、表格节点） | 文本内容 |

工具条里还有一排**素材槽**，可以给这个节点额外挂上参考图（比如某一镜要多参考一张服装图）。改完配置后点「生成」或「重新生成」即可生效。

> 💡 **提示**：在「生成」模式下写的画面描述，会连同上方的参考图一起发给模型；留空则沿用分镜表里的描述。

### 7.3 增删节点与连线

| 操作 | 怎么做 |
|:---|:---|
| 添加独立节点 | 底部工具条「添加节点」→ 选图片 / 视频 / 音频 |
| 在某节点后面接一个新节点 | 悬停该节点，点右侧的「添加后续节点」，新节点会自动连上 |
| 连线 | 从一个节点的右侧把手拖到另一个节点的左侧把手 |
| 删除节点 | 选中后按 `Delete` / `Backspace`，或点节点工具条上的删除按钮；相连的连线一并删除 |
| 删除连线 | 悬停连线，点出现的删除按钮 |
| 调整节点大小 | 拖动节点右下角 |

你手动做的这些改动会被记录下来，之后助手改图时会尽量保留你的调整。

### 7.4 查看与编辑产出物料

- 点节点上的**「查看物料」**，可以看大图、播放视频、阅读文本，用左右箭头在所有物料间切换。
- **创意简报**和**分镜表**可以在查看器里直接点「编辑」修改并保存。保存后，重跑下游节点会读到新内容。
- 如果文件在你编辑期间被其他操作更新了，查看器会提示你选择"用草稿覆盖"还是放弃。

### 7.5 素材包

左侧「素材」标签和底部「素材包」按钮打开的是同一份列表，收集了这个项目里所有的文件：

- **来源**：你上传的（标记"上传"）和模型生成的（标记"生成"）；
- **状态**：已经挂在某个节点上的显示"画布中"，只在素材库里的显示"仅素材库"；
- 把素材**拖到画布上**，会自动生成一个对应类型的上传节点；
- 不需要的素材可以删除。

## 8. 文件放在哪里

所有文件都在 JiuwenSwarm 的数据目录下（默认 `~/.jiuwenswarm`，可通过环境变量 `JIUWENSWARM_DATA_DIR` 修改）：

| 内容 | 路径 | 说明 |
|:---|:---|:---|
| 项目产物 | `agent/workspace/design/<项目名-8位编号>/assets/` | 生成的图片、视频、简报 `.md`、分镜表等，以及你上传的素材 |
| 画布定义 | `agent/designer/graphs/<graph_xxx>.json` | 节点、连线和配置 |
| 运行记录 | `agent/designer/runs/<run_xxx>.json` | 每次执行的节点状态 |
| 评分反馈 | `agent/designer/feedback/<graph_xxx>/` | 导演智能体对每次运行的自评，用于下一次优化 |
| 轨迹记录 | `.trace/designer/<项目编号>.otlp.jsonl`、`.design.jsonl` | 在主配置里打开 `trajectory_ui.enabled` 后才会写入。项目编号可以从浏览器地址栏看到：打开某个设计项目时，地址是 `/design/proj_xxxxxxxx`，最后一段就是文件名里的项目编号。两个文件各记一类内容，见下方说明 |

轨迹的两个文件：

- **`.otlp.jsonl`**：一行一条，记录每次模型调用的提示词、工具的参数和返回、以及耗时；
- **`.design.jsonl`**：记录设计过程本身，包括每次运行的基本信息、导演和各节点之间的协作、评分反馈，以及每个节点智能体的运行摘要。

这两份记录都可以在轨迹面板中查看。

> 💡 **提示**：直接拷贝 `assets/` 目录就能拿走一个项目的全部成品。

## 9. 常见问题

**节点失败，提示 "not configured" 或 "switched off"**

对应的图像 / 视频生成模型没配置或开关没打开。按第 2 节补好后，点该节点的「重新生成」。

**我写了 480p，为什么生成出来不是？**

先确认描述里写的是 `480p` 这种带 p 的写法（大小写都行）。如果所配模型本身不支持这一档，系统会自动换成它支持的最接近档位。

**为什么没有旁白 / 配音节点？**

当前版本的设计工作流不生成独立旁白；视频里的声音由视频模型自带的音频能力负责（在节点工具条里勾选"有声音"）。背景音乐需要配置音乐模型后才会出现音乐节点。

**执行很久没反应**

视频生成是异步任务，一镜通常要几分钟。系统最长会等 30 分钟（自建 vLLM-Omni 为 2 小时），超时才会把节点标为失败。可以切到其他页面做别的事，回来后状态会同步。

**不小心把节点删了**

和助手说"把刚才删掉的关键帧 3 加回来"，或者用底部「添加节点」手动补一个再连上线。

**想换一个模型重跑**

默认模型在设计首页右下角选择，或在「配置信息」里改；图像、视频模型在「配置信息 → 智能体」里改。改完后对相关节点点「重新生成」。
