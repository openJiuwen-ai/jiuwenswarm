# AgentTeam 人类成员联机协作（HITT）

## 简介

在 Agent Team 中，除了全自动的 AI 成员外，你还可以**让真实人类作为团队成员加入**，与 AI 一起协作。

典型场景：Web 端创建一个团队（如五子棋游戏、代码 review 小组），生成人类席位，其他人通过飞书或小艺 `/join` 加入，以该席位的身份参与团队对话。

> 团队中的每个人类身份（如 `玩家1`）对应一个 Agent。你的发言会驱动这个 Agent 执行操作；而 AI 成员会自己认领任务、自主发言。
>
> HITT 功能**默认开启**，无需额外配置。如果你的团队配置中显式设置了 `enable_hitt: false`，人类成员将不可用。

---

## 一、整体流程

### 1.1 Web 端发起团队

在 Web 端切换到集群模式，用自然语言创建包含人类席位的团队。例如：

```
组建一个五子棋游戏团队，leader 作为主持人，包含 1 个人类玩家席位。
人类玩家加入后 leader 询问玩家的准备情况，等玩家确认准备好了就开始游戏。
棋盘使用 Markdown 表格，表示 5x5 五子棋棋盘。
```

创建成功后，界面会弹出邀请框，显示类似：

```
团队成员加入指令：

  /join sess_abc123 as 玩家1

退出指令：

  /exit
```

团队创建后，该 Web 页面拥有上帝视角，可以看到所有成员的对话和 Leader 的输出。

### 1.2 飞书 / 小艺加入

复制邀请框中的 `/join` 指令，在对应渠道发送：

**飞书群**：@ 机器人后发送
```
@机器人 /join sess_abc123 as 玩家1
```

**飞书私聊 / 小艺**：直接发送
```
/join sess_abc123 as 玩家1
```

系统回复确认后，你就以"玩家1"的身份加入了团队。

### 1.3 退出

```
/exit
```

退出席位。

## 二、消息交互

### 2.1 发言规则

**Web 端**：直接对话即为与 Leader 交流；要驱动你的 Agent，输入 `$成员名 内容`。

**飞书 / 小艺**：`/join` 后系统自动以你的席位身份驱动 Agent，直接对话即可。

例如飞书用户 `/join` 为 `玩家1` 后，输入"我准备好了"，系统自动翻译为 `$玩家1 我准备好了` 驱动 Agent 执行。

### 2.2 `$` 语法

`$` 前缀用于驱动人类成员 Agent，支持三种用法：

| 语法 | 含义 | 示例 |
|------|------|------|
| `$成员名 内容` | 驱动 Agent，内容发给 Leader | `$玩家1 我下在第3行第3列` |
| `$成员名 @目标 内容` | 以 Agent 身份给另一个成员发私信 | `$玩家1 @玩家2 轮到你了` |
| `$成员名 @all 内容` | 以 Agent 身份向全团队广播 | `$玩家1 @all 我认输` |

在飞书/小艺中，`$成员名` 由系统自动拼接，你只需正常对话或用 `@` 即可。

> **空格规则**：`$成员名` 后必须有空格。`$玩家1@玩家2`（无空格）会被错误解析。

### 2.3 接收消息

其他成员 @ 你或 Leader 给你发消息时：
- **飞书 / 小艺**：消息投递到你的私聊或群聊
- **Web 端**：在团队对话界面显示



### 2.4 完成任务

Leader 给你指派任务后，向你的 Agent 发指令让它执行。人类成员的任务不会自动完成——需要你驱动 Agent 来执行。

## 三、常见问题

### Q1：Web 端如何驱动人类成员 Agent？

Web 端直接对话是与 Leader 交流；要驱动人类成员 Agent，需要在输入内容前加 `$成员名`，例如 `$玩家1 我下在第3行第3列`。飞书和小艺 `/join` 后无需手动加，系统自动拼接。

### Q2：我的 Agent 能做什么？

完整的文件操作、shell 命令。Leader 可以给它指派任务，但工具调用和确认任务完成都需要你驱动。

### Q3：Web 端发起者和人类成员的角色有什么不同？

Web 端发起团队的页面拥有上帝视角，能看到所有成员对话和 Leader 输出，直接对话即与 Leader 交流。人类成员是通过 `/join` 加入的席位参与者，发言时需要用 `$成员名` 标明身份（飞书/小艺自动拼接），只能看到发给自己的消息。
