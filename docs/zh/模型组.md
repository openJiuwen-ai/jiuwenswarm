# 模型组

> **目标**：帮助读者了解 JiuwenSwarm 的模型组功能，掌握模型组的创建、编辑、删除方法，以及在集群模式中使用模型组并了解其故障切换规则。
>
> **英文版：** [Model Groups](../en/ModelGroups.md)

---

## 1. 概述

模型组是将多个已配置模型组合为一个整体进行管理和调用的功能，目前仅服务于集群模式。您可以把多个模型加入同一个模型组，并通过排序决定各模型的调用顺序。团队执行任务时，若当前模型调用失败，系统会自动改用组内下一个模型，避免任务因单个模型故障而中断。

### 1.1 核心概念

| 概念 | 说明 |
|------|------|
| **模型组** | 由一个或多个已配置模型组成的集合，在集群模式下可作为一个整体被选择 |
| **成员模型** | 模型组中的单个模型，必须来自「模型」标签页中已配置的自定义模型 |
| **组内默认** | 模型组中排在第一位的模型，团队优先使用该模型 |
| **调用顺序** | 成员模型在组内的排列顺序，排序越靠前，调用优先级越高 |
| **故障切换** | 当前模型调用失败时，自动按调用顺序改用组内下一个模型 |

### 1.2 适用场景

- **主备容灾**：将不同提供商的同款模型加入同一个模型组，主模型出现故障时，团队自动改用备用模型继续执行任务
- **应对限流**：团队成员同时调用模型时容易触发限流，模型组可在某个模型被限流时自动切换到其他模型
- **统一管理**：将常用模型集中在一个模型组中管理，在集群模式下一次选中即可使用

## 2. 配置与使用

### 2.1 添加与管理模型组

> ⚠️ **前提**：需先在「**模型**」标签页中添加至少一个自定义模型（详见 [配置信息](./配置信息.md)），限时免费模型不支持加入模型组。

1. 打开「**设置**」→「**模型**」，切换到「**模型组**」标签页，点击「**添加模型组**」
2. 填写**模型组名称**，点击「**添加模型**」从下拉框中选择成员模型（套餐类模型在「提供商–套餐」二级菜单中选择），可添加多个
3. 拖拽调整顺序，或点击某行的「**组内默认**」将其移至首位，然后点击确认保存

![模型组标签页](../assets/images/模型组标签页.png)

> 💡 **提示**：排序即调用顺序，首位为组内默认模型，建议放最稳定、最常用的模型。

保存后，模型组以卡片形式展示，点击卡片标题可展开成员列表，对每个成员执行「**组内默认**」「**测试连接**」或「**从模型组中移除**」。模型组至少需保留一个模型。
![模型组卡片展开后的成员模型列表](../assets/images/模型组卡片展开.png)

### 2.2 编辑与删除模型组

在模型组卡片右上角：

- **编辑**：点击「**编辑模型组**」，可修改模型组名称，增删或替换成员模型，并调整调用顺序
- **删除**：点击删除图标并确认即可删除。若模型组正被 Team 任务使用，需先将该任务切换为其他模型或模型组，才能删除

> ⚠️ **注意**：若成员模型显示「模型不可用」，说明它引用的模型已在「模型」标签页中被删除或失效，请编辑模型组将其替换或移除。

### 2.3 在集群模式中使用模型组

1. 切换到集群模式，详见：[模式系统](./模式系统.md)
2. 点击对话输入框附近的模型选择器，在「**模型组**」分类下选择目标模型组
3. 发送任务

![集群模式下模型选择器中的「模型组」分类](../assets/images/集群模式选择模型组.png)

若模型选择器中没有可用模型，可点击「**添加自定义模型/模型组**」快速进入设置页面。

团队成员默认统一使用组内默认模型，该模型调用失败时自动按顺序切换到下一个模型。如需让某个成员使用组内的其他模型，直接在任务中说明即可；只能指定当前模型组内的模型，若指定的模型不在组内，Leader 会先向您确认，而不会自行替换。

**使用示例**

选中模型组后发送：

```text
创建一个包含 2 个成员的 team，给两个成员分配任务：各自在团队共享工作区写入一个文件，成员 A 写入 group_report_A.txt，成员 B 写入 group_report_B.txt，文件内容为自己的名字，完成后向 leader 发送完成汇报。启动后不要反复催促，等待成员执行完成。
```

![模型组使用示例执行结果](../assets/images/模型组使用示例.png)

此外，还可以在任务中指定某个成员使用组内的某个模型，例如让成员 A 使用 deepseek-v4-flash：

```text
创建一个包含 2 个成员的 team，其中成员 A 使用 deepseek-v4-flash 模型。给两个成员分配任务：各自在团队共享工作区写入一个文件，成员 A 写入 group_report_A.txt，成员 B 写入 group_report_B.txt，文件内容为自己的名字，完成后向 leader 发送完成汇报。启动后不要反复催促，等待成员执行完成。
```

![指定成员模型的执行结果](../assets/images/模型组指定成员模型示例.png)

### 2.4 故障切换与报错

团队调用模型时，会先使用组内默认模型。组内某个模型调用失败时，系统会暂时跳过它，自动按顺序改用组内下一个模型，无需手动操作：

```text
模型 A（组内默认） -> 模型 B -> 模型 C
```

- **自动切换**：模型服务暂时出现问题（如网络连接不上、响应超时、请求被限流、服务端故障），或模型配置有误（如 API 密钥错误、模型名称错误），团队都会改用下一个模型继续执行
- **暂时跳过**：调用失败的模型会被暂时停用，一段时间后系统会再次尝试；连续失败时，停用时间会逐次延长
- **回复中途出错**：模型已经开始输出回复后出错，不再切换，已输出的内容会保留，本次回复以错误结束
- **全部失败**：组内所有模型都不可用时，本次调用报错

> 💡 **提示**：配置有误的模型会被一直跳过，但界面上可能没有报错。建议保存模型组后，对组内模型逐个执行「测试连接」，确认都可用。
