# RSI 优化产物安装

HARNESS 任务完成且引擎发布了最终产物后，在 RSI 详情页点击“安装”。
接口仍为 `rsi.harness.install`，参数仍为 `{"task_id": "..."}`，返回结构不变。

安装成功后：

- 保留任务目录中的不可变 Harness 版本，供 RSI 激活和回退。
- 通过现有插件导入、安装机制，将独立副本登记到
  `<AgentWorkspace>/plugins/plugin_packages/local/rsi-harness-<内容hash前16位>/`。
- 前端刷新现有插件列表，在“扩展”中可以选择使用；不必手动移动文件。
- 展示名带有 `RSI` 和版本短标识，与原插件区分。
- 新版本使用独立 ID，不覆盖原插件。当前已激活的 RSI 版本再次被选择时不会重复挂载。

原生 `DeepAgent.load_plugin` 未修改。JSON 插件声明原样保留能力和展示信息；
旧 YAML 产物由 SDK 解析后转换为原生 JSON 声明。无法无损表达的旧注册式工具或
Rail 会明确报错，不会以“只有卡片、没有能力”的方式伪装安装成功。

重复安装可补齐旧安装缺失的扩展登记。若导入、激活或任务记录写入失败，回滚本次
新增的登记；不删除其他插件，也不覆盖被用户编辑的已登记版本。

更新服务代码后需要重启后端才能启用此安装逻辑；不要为了更新而中断正在运行的训练。
