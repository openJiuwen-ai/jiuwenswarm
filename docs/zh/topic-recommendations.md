# 话题推荐

在 **设置 → 常规** 中打开“话题推荐”时，已有推荐模型配置会直接启用，不再弹出配置框。仅在未配置模型时，弹窗要求填写模型提供商、OpenAI 兼容协议、API Key 和模型，再点击“保存并启用”。取消配置或保存失败时，开关保持关闭。点击模型卡片上的修改按钮可重新打开配置框。未配置推荐模型时，不自动使用聊天模型，也不显示默认模型卡片。

弹窗采用与视频生成模型配置相同的连接表单，只展示模型提供商、OpenAI 兼容协议、API Key、模型；自定义提供商还需填写 API 地址。无需模型别名、推理级别或上下文窗口。

保存后，开关下方显示模型名称及编辑、删除入口。推荐连接独立保存，不会添加到 **设置 → 模型**。关闭开关保留配置；删除会清空独立配置、解除旧绑定并关闭推荐。旧聊天模型不会自动显示成推荐模型。

编辑时，API Key 输入框回填已保存的真实密钥，默认以密码形式隐藏，点击眼睛可查看或再次隐藏。普通状态查询不返回密钥，仅编辑框显式请求读取。填写新密钥并保存会替换原值。

开启时，首页在后端提供推荐内容后展示话题卡片，尚无内容时不展示关闭引导。只有关闭时才显示打开推荐的文字提示及跳转到 **设置 → 常规** 的链接。

话题检索需要在 **设置 → 智能体** 中同时启用 DuckDuckGo 和 Bing 免费搜索。若服务启动时搜索尚未配置，保存搜索配置后，下次读取推荐会重新创建话题服务，并保留已有准备任务和结果队列。

开启“提示词推荐”后，回答完成且输入框为空时，后端生成的下一步提问会显示在输入框灰色占位文字处，并提示按 Tab 填入。建议不受消息区滚动位置影响；Tab 或右方向键只将建议填为可编辑草稿，按发送后才提交。直接输入其他内容或开始下一轮问答会隐藏旧建议；后端尚未提供建议时显示原占位文字。首页话题推荐和提示词推荐使用独立开关。

建议只在输入框显示正文，不在回答下方重复展示标签，也不添加“下一步：”前缀。切回会话或恢复连接时会补读最新问答尚未使用的建议；已接受、忽略或失效的建议不会恢复。
