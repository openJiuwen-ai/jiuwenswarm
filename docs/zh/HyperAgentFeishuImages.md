# HyperAgent 飞书群图片问答

在同一条飞书群消息里 @ AI 同事、粘贴截图并写下问题，例如“红框里写了什么？蓝色圆形在哪里？”支持图文混排和多图，按发送顺序编号。历史消息中的图片请随问题重发。

**管理员配置**

1. 确认同事绑定的飞书机器人有权读取该消息并下载原图。
2. 在「设置 → 模型 → 多模态模型」添加支持图片的模型，填写模型 ID、API 地址和密钥。
3. 在「设置 → 智能体 → 工具 → 图片处理」开启功能并选择该模型。

每条消息最多 8 张图片，单张最多 20 MiB、4000 万像素。准备图片最多等待 45 秒；视觉调用默认等待 60 秒，可通过 `VISION_REQUEST_TIMEOUT_SECONDS` 调整。

升级后，请重新发送尚在运行或等待审批的旧版 WeLink 附件任务。
