# Jev 模型配置

在「设置 > 模型 > 决策模型」配置一次，浏览器决策和多模型协同校验共用同一提供商、地址、密钥和模型。
沿用原浏览器配置模板和保存位置（`browser.decision` 与对应的环境变量密钥），已有浏览器配置无需重新录入。

## 共享模型

在「Jev 模型」中点击「添加模型」进行配置，当前最多配置一个，保存后可编辑：

| 提供商 | API 地址 | 默认模型 |
| --- | --- | --- |
| OpenRouter | 内置 `https://openrouter.ai/api/alpha` | `typesafe/jev-1.13` |
| TypeSafe | 内置 `https://api.typesafe.ai/v1` | `jev-1.13.0` |
| 自定义 | 必须填写 HTTPS 基础地址 | `jev-1.13.0`，可修改 |

表单包含提供商、API 密钥、模型、展示名称，以及自定义提供商的 API 地址。展示名称默认使用模型名，可修改。
已有密钥自动回填，默认掩码显示，可点击可见性按钮查看；未配置时为空。
取消不会保存。切换提供商会使用对应模板和独立密钥，填写完成后点击保存。

自定义服务须兼容 TypeSafe Jev `/systemone` 接口，填写不带 `/systemone` 的基础地址；
它不是普通 Chat Completions 服务。OpenRouter 则使用其原生 Jev `/decisions` 接口。
不提供协议或上下文窗口配置。

## 独立开关

- 浏览器决策模式（LLM / Shadow / Hybrid）仍位于「浏览器」设置。
- 多模型协同总开关、JEV 决策开关和验证间隔仍位于「实验功能」。
- 保存共享模型不会自动启用任何能力；浏览器处于仅 LLM 模式时，多模型协同仍可独立使用 Jev。
- 删除模型会清空当前密钥和展示名称，将浏览器切回仅 LLM，并关闭多模型协同的 JEV 决策；其他提供商密钥不受影响。
- 未配置密钥时启用 Shadow / Hybrid，会按界面语言提示并保持原模式；离开浏览器设置后提示清除，返回时不再显示。

两条调用链均按共享提供商选择 `/decisions` 或 `/systemone`。多模型任务重新构建运行时时会读取
最新共享配置。Chrome 路径、显示模式、登录态和生命周期不受影响。

## 旧配置

旧的 `experimental.multi_model_collaboration.jev` 内容保留但不再读取，不自动覆盖浏览器配置。
如果此前只配置过独立的多模型 Jev，请在统一入口配置一次；旧 `moa_jev_api_*` 和
`moa_jev_model_name` 写入请求会明确提示使用新入口，不会静默保存无效配置。
