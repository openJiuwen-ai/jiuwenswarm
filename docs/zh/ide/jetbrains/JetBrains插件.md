# 面向 JetBrains 的 JiuwenSwarm

JiuwenSwarm 插件将一个自主多智能体 AI 编码助手直接嵌入 PyCharm、IntelliJ IDEA、WebStorm、
GoLand 以及所有其他 JetBrains IDE（2023.1+）。面板位于停靠的工具窗口中，逐 token 流式输出
回复，并通过 diff 审查、终端集成、文件链接导航和 Alt+Enter 快速修复菜单与编辑器集成。

## 安装

前置条件与安装说明参见 [JetBrains插件安装.md](JetBrains插件安装.md)。

## 配置

打开 **设置 → 工具 → JiuwenSwarm**：

| 设置项 | 默认值 | 说明 |
|---|---|---|
| 服务器主机 | `127.0.0.1` | JiuwenSwarm 服务器的主机名或 IP |
| 服务器端口 | `19000` | WebSocket 端口——连接 `ws://host:port/ws` |
| 频道 ID | `ide` | 服务器日志中显示的客户端标识 |
| 启动时连接 | 开 | IDE 启动时打开 WebSocket |
| **默认模式** | `code.plan` | 应用于新会话的模式（计划与执行 / 执行 / 团队编码） |
| 自动应用文件编辑 | 关 | 立即应用智能体编辑，不打开 diff 窗口 |
| 编辑前要求批准 | 关 | 应用任何智能体文件编辑前显示确认提示 |
| 在 IDE 终端中运行命令 | 开 | 在专用终端标签页中显示智能体 shell 命令 |
| 保活 ping 间隔 | 30 秒 | WebSocket ping 帧之间的秒数（5–300） |
| 包含项目树 | 开 | 在每条消息前附加项目根目录的目录列表 |
| 项目树最大文件数 | 200 | 项目树列表的最大条目数（10–2000） |
| 切换会话时加载历史 | 开 | 切换到已有会话时获取并显示历史消息 |
| 启用检查点 / 回退 | 开 | 在智能体编辑前快照文件；每轮后显示回退栏 |
| **Git 快捷操作** | 关 | 在消息列表下方显示提交 / 推送按钮 |

## 键盘快捷键

| 操作 | Windows / Linux | Mac |
|---|---|---|
| 新会话 | `Ctrl+Shift+J` | `⌘⇧J` |
| 将选中内容发送到聊天 | `Ctrl+Shift+E` | `⌘⇧E` |
| 用 JiuwenSwarm 修复 | `Alt+Enter` | `⌥Enter` |

## 面板包含什么

### 聊天输入

在底部文本框中输入消息。三个输入快捷键会触发内联选择器：

| 触发键 | 出现内容 |
|---|---|
| `@` | 文件自动补全——从工作区文件中选取并注入完整文件内容 |
| `#` | 技能选择器——列出已注册技能并插入技能名 |
| `!` | 预设提示——八个内置模板（解释、修复 Bug、写测试、重构、优化、写文档、审查、实现） |

使用**方向键**导航，**Enter** 或 **Tab** 选择，**Escape** 关闭。**Enter** 发送消息；
**Shift+Enter** 插入换行。

使用 **+** 按钮附加图片（PNG、JPEG、WebP、GIF；每张最大 10 MB）。

### 模式选择器

| 模式 | 键 | 行为 |
|---|---|---|
| 计划与执行 | `code.plan` | 智能体探索并提出计划；在编辑文件前等待你的确认 |
| 执行 | `code.normal` | 智能体直接编辑文件并运行命令 |
| 团队编码 | `code.team` | 主智能体为大型任务并行分配子智能体 |

### 消息列表

- 回复逐 token 流式输出，并完整渲染 Markdown（代码块、表格、列表、标题）。
- **思考块** —— 扩展的模型推理出现在回复上方的可折叠区域。
- **工具调用卡片** —— 每个工具调用都会内联显示，带实时状态指示、可折叠输入和可折叠输出。
- **文件链接** —— 智能体回复中的文件路径可点击，并在引用行打开该文件。
- **符号链接** —— 反引号中的 PascalCase 和 SCREAMING_SNAKE_CASE 标识符是紫色链接，
  可跳转到项目中的符号。

### 统计与指标

- **上下文栏** —— 输入框下方的一条细栏，显示模型上下文窗口的占用程度。
- **token 计数器** —— 发送按钮旁显示每轮 token 数；IDE 状态栏部件显示会话总量。
- **会话统计片** —— 总轮数、token、成本、工具调用、平均延迟，以及工具构成片。
- **迷你图表** —— 可折叠的条形图，显示每轮的 token 和耗时。
- **服务器内存** —— 统计栏中显示服务器实时内存使用（每 10 秒轮询）。

### 每条消息自动发送的上下文

| 字段 | 来源 |
|---|---|
| 活动文件路径与语言 | `FileEditorManager` + `FileType` |
| 光标行 | `Editor.caretModel` |
| 选中的代码 | `Editor.selectionModel` |
| 编辑器诊断（最多 10 条） | 文档标记模型 |
| 其他打开的标签页（最多 10 个） | `FileEditorManager.openFiles` |
| 项目树（2 层） | `LocalFileSystem` 遍历 |
| Git 分支与变更数 | `git` 子进程 |
| 项目规则 | `.jiuwenswarm/instructions.md`、`.jiuwenswarm/rules.md` 或 `AGENTS.md` |
| @提及的文件 | 消息中每个 `@path` 的完整文件内容 |

### 文件编辑工作流

当智能体调用文件编辑工具（`str_replace_editor`、`write_file`、`create_file`）时，插件会
拦截它：

- **默认**：打开并排 diff 窗口（当前 vs 拟议）。关闭窗口即应用。
- **自动应用**：通过 `WriteCommandAction` 立即写入编辑（可用 `Ctrl+Z` 撤销）。
- **要求批准**：在打开 diff 或应用前出现确认提示。

### 终端集成

智能体 shell 命令（`bash`、`run_command`）在专用 **JiuwenSwarm** 终端标签页中运行，因此
输出可见且可滚动。终端在第一条命令时创建并复用。可在设置中关闭以静默运行命令。

### 检查点 / 回退

任何编辑过文件的轮次结束后，消息列表下方会出现回退栏。点击**撤销更改**可将所有修改过的
文件恢复到该轮之前的状态。你发送下一条消息时快照被清除。

### Git 快捷操作

在设置中启用 **Git 快捷操作**，可在消息列表下方显示**提交**和**推送**按钮。**提交**打开
对话框，预填你最后的消息作为提交消息，运行 `git add -u && git commit -m <message>`。
**推送**立即运行 `git push`。

### 会话

点击 **⚙ → 会话** 打开会话列表。切换、创建（新建按钮或 `Ctrl+Shift+J`）或删除会话。开启
**切换会话时加载历史**后，切换后历史消息会自动流式加载。

### 技能

点击 **⚙ → 技能** 查看已注册技能。每个技能显示其名称、说明、触发词和开/关开关。在聊天
输入框中输入 `#` 即可选择技能，无需打开浮层。

### Swarm Map

在**团队编码**模式（`code.team`）下可用。第一个团队智能体生成时会自动在 IDE 底部打开——
无需点击。

面板有三个视图，通过页头中的 **Map / List / Board** 开关切换（Map 为默认）：

| 元素 | 显示内容 |
|---|---|
| Map 视图 | 交互画布：智能体为彩色节点，工作时脉冲，完成时显示 ✓；动画流动点；拖拽平移、滚轮缩放、点击查看详情 |
| List 视图 | 每个工作线程一张泳道卡片——状态片、实时耗时、当前动作、可滚动活动流 |
| Board 视图 | 三列看板（待办 / 进行中 / 完成）；每个任务一张卡片，带智能体颜色点和阻塞/完成/取消徽标 |
| 进度片 / 进度条 | `N/M 个任务 · K 个智能体 · M 个工作中` + 完成任务百分比条 |
| 任务胶囊（List） | List 视图中的每任务一个胶囊；颜色从黄色（待处理）→ 绿色（进行中）→ 红色（阻塞）→ 灰色（已完成）变化 |
| ↗ 打开文件 | 悬停带有活动文件的泳道卡片可看到提示；点击在编辑器中打开文件 |
| 消息日志 | 可折叠的 `▶ 消息 (N)` 开关，显示智能体之间的消息，按发送者着色 |
| 调试控制台 | ☰ 菜单 → **调试日志**（默认关闭）：实时团队事件与工具归属日志，带清除/复制 |
| 摘要卡片 | 所有工作线程完成时替代泳道：智能体数量、完成任务数、消息数、各智能体耗时 |

完整参考见 [JetBrains插件指南.md — Swarm Map](JetBrains插件指南.md#swarm-map)。

## Alt+Enter 快速修复

将光标放到任意错误或警告上，按 **Alt+Enter**。**用 JiuwenSwarm 修复** 会出现在菜单中。
它会预填错误消息和周围 ±7 行代码。

## 连接状态栏

IDE 状态栏显示实时 WebSocket 状态：

| 符号 | 含义 |
|---|---|
| `⬤ JiuwenSwarm`（青色） | 已连接 |
| `◌ JiuwenSwarm`（青色） | 连接中 |
| `↻ JiuwenSwarm`（黄色） | 重连中（指数退避：1 秒 → 最大 30 秒） |
| `○ JiuwenSwarm`（灰色） | 已断开——点击重新连接 |

一旦消耗 token，标签旁会显示总量：`⬤ JiuwenSwarm · 42.3k`。

## 项目规则

在项目根目录创建 `.jiuwenswarm/instructions.md`（或 `.jiuwenswarm/rules.md` 或
`AGENTS.md`）。插件会读取它找到的第一个文件，并将其内容附加到每条消息的**项目规则：**
标题下。可用于按项目设定编码规范、禁止模式或偏好的库。

## 故障排查

| 症状 | 解决方法 |
|---|---|
| 面板空白 | 通过 **帮助 → 查找操作 → 注册表** 启用 `ide.browser.jcef.enabled`，然后重启 |
| 状态栏显示 `○` | 启动 JiuwenSwarm；核对设置中的主机/端口；点击部件重连 |
| 无回复流式输出 | 启用调试日志（**⚙ → 调试日志**）并检查错误帧 |
| diff 窗口打开但文件未变 | 关闭 diff 窗口——变更在关闭时应用，而非立即 |
| 缺少回退栏 | 检查设置中的**启用检查点 / 回退**；确认轮次正常完成 |
| Alt+Enter 不显示选项 | 光标必须位于带有红色或黄色槽口标记的行上 |
