# 本地插件与广场插件的替换

安装广场插件时，如果本地已存在相同插件 ID 的包，会先显示确认弹窗。选择“取消”保留原包；选择“替换本地版本”使用广场版本覆盖本地包，本地修改将被覆盖，不比较版本高低。

如果旧插件正在执行任务或关闭资源，本次替换会被拒绝，请待空闲后重新安装并确认。替换保留插件 ID 和包外经验数据；失败时恢复旧包、安装记录和在线会话原有的插件选择。只有显示名称相同的不同插件不会因此被覆盖。

普通本地与内置插件安装不需要查询广场，可在广场不可用时继续安装已有定义。流式消费任务结束或取消后，宿主会关闭未显式关闭的流，并在资源清理完成后释放插件占用。

如果只看到确认要求的错误提示而没有弹窗，请确认前端构建已更新，并强制刷新浏览器页面。
