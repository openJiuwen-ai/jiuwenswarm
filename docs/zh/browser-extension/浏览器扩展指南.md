# 用户指南

## 概述

JiuwenSwarm 浏览器是一款 Chrome 扩展，让 JiuwenSwarm AI 智能体常驻于你正在阅读的
任意网页旁。与独立的聊天界面不同，它会读取当前标签页的内容，让你把多个页面固定到单个
**研究会话**中，并允许智能体与你屏幕上看到的内容直接交互。

---

## 核心概念

### 研究会话
一个有名字的对话范围。所有固定页面、聊天历史和智能体上下文都属于某个会话。你可以拥有
多个会话并随时切换。会话存储在 JiuwenSwarm 服务器上——它们也会出现在网页端，因此你
可以在浏览器中开始研究，再到网页端继续。

### 固定页面（Pinned Page）
添加到当前会话上下文中的页面提取文本快照。当你发送消息时，智能体会自动收到所有固定
页面的合并文本作为背景上下文——无需复制粘贴。

### 侧边面板
主要界面。它在页面旁边打开（而非覆盖），因此你可以边读边聊，不会丢失位置。

## 快速上手

### 打开侧边面板

三种打开方式：

| 方式 | 操作 |
|---|---|
| 键盘快捷键 | **Ctrl+Shift+J**（Mac：**Cmd+Shift+J**） |
| 工具栏图标 | 点击 JiuwenSwarm 图标 → **打开面板** |
| 右键菜单 | 右键任意页面 → **固定此页面**、**取消固定此页面**、**总结此页面** 或 **此页面的智能体视角** |

> **首次使用？** 首次打开面板时会有一段简短的 3 步引导，解释核心流程。你随时可从 **⋯**
> 菜单 → **上手引导** 重播。

### 创建第一个会话

1. 打开侧边面板。
2. 点击 **+ 新建**（面板右上角）。页头下方会出现一个小表单。
3. 输入会话名称。
4. 选择**模式**（研究、聊天、总结或对比）。
5. 点击**创建**。会话立即生效。

下次打开面板时会自动恢复你最近的活动会话。点击页头中的会话名即可打开会话选择器切换会话。

## 使用页面

### 固定页面

固定会提取页面的主要内容，并将其加入当前会话的上下文。智能体在回答你的问题时会用到它。

**方式：**
- **键盘：** 在任意标签页按 **Ctrl+Shift+P**（Mac：**Cmd+Shift+P**）。
- **按钮：** 打开侧边面板 → 点击 **📌 固定页面**（悬停可查看快捷键）。
- **右键：** 右键页面 → **固定此页面**（或 **取消固定此页面** 将其从会话中移除）。

> 如果你还没有创建会话，固定会先打开 **+ 新建** 表单——先创建会话，再固定。在没有活动
> 会话时尝试发送消息也会出现相同情况；空状态中还会显示 **+ 创建会话** 按钮。

被固定的页面会以「片」（chip）的形式出现在页头下方的上下文栏中。固定时会显示确认 toast，
工具栏徽标会显示已固定到当前会话的页面数量。

- **重排** —— 使用片上的 **◀ ▶** 按钮改变上下文优先级（靠前的片会先发给智能体）。
- **预览** —— 点击任一片可展开提取文本的预览，让你看到智能体将读到什么。再次点击收起。
- **撤销取消固定** —— 点击 **×** 移除页面并显示**撤销** toast。在几秒内点击**撤销**即可恢复。
- **键盘** —— 片获得焦点后，按 **← / →** 移动到上一个/下一个片。

悬停到片上可查看完整 URL、页面类型以及提取了多少字符。

### 提取质量信号

上下文栏中的每个片都显示提取相关的信息：

- **工具提示** —— 悬停任一片可查看完整 URL、页面类型和提取的字符数。
- **⚠ 告警** —— 带红色边框和告警图标的片表示提取到的文本很少（少于 200 字符）。这通常
  意味着页面是 JS 渲染的，需要片刻加载，或位于登录墙之后。尝试在页面完全加载后取消固定再重新固定。
- **PDF 徽标** —— 页面是直接在 Chrome 中打开的 PDF。内容脚本无法提取二进制 PDF；
  若该工具可用，**↻** 重试按钮会通过 JiuwenSwarm 服务器的 `read_pdf` 工具重新尝试提取。
- **↻ 重试按钮** —— 出现在告警片和 PDF 片上。点击可取消固定旧版本并重新提取页面的当前状态。

### 页面类型

扩展会自动检测页面类型并应用专门的提取器：

| 页面类型 | 提取内容 |
|---|---|
| **文章 / 新闻** | 通过 Readability.js 提取正文 |
| **GitHub** | README、issue/PR 正文、评论、仓库描述 |
| **arXiv** | 标题、作者、摘要、论文全文 |
| **SEC EDGAR** | 申报内容、10-K/10-Q/8-K 文档正文 |
| **PubMed** | 摘要、全文（PMC）、作者、MeSH 词 |
| **Wikipedia** | 引言部分 + 条目正文；剥离参考文献与导航框 |
| **YouTube** | 视频标题、频道、描述，以及自动生成的字幕（如可用） |
| **Twitter / X** | 推文串文本（含引用的推文）；处理多回复串 |
| **Hacker News** | 提交标题和 URL、顶层评论；首页链接列表 |
| **通用** | 其他任意页面的 Readability.js 兜底 |

> 直接在 Chrome 中打开的 **PDF** 会被检测并以 **PDF** 徽标显示。从二进制 PDF 提取文本
> 需要服务器端的 `read_pdf` 工具。

### 跨多标签页研究

1. 打开几个标签页——一篇论文、一家公司的投资者页面、一篇新闻。
2. 用 **Ctrl+Shift+P** 固定每个标签页。
3. 所有固定页面都以片的形式出现在上下文栏中。
4. 在侧边面板中向智能体提问——它会收到所有固定内容作为上下文。

固定三个页面后的示例提示：
> 「比较这三个来源中的营收增长说法，并标出任何矛盾之处。」

## 使用聊天

### 发送消息

在侧边面板底部的聊天输入框输入消息，按 **Enter**（或点击发送）。智能体组织回复时会显示
一个小型脉动指示器；收到前几个字后即替换为回答。

在第一条消息之前，会出现一键**建议片**帮助你起步——「总结此页面」，以及「比较所固定的
页面」（仅当你固定了至少两个页面时出现）。

智能体会自动收到：
- 你的消息
- 固定到当前会话的所有页面的合并文本
- 会话模式（研究 / 聊天 / 总结 / 对比）

### 阅读回答

智能体的回复以 **Markdown** 渲染——标题、项目符号列表、行内代码和代码块、链接都以格式化
方式显示，而非原始文本。点击回答中的任意链接即可在新标签页打开。

- **复制** —— 一键抓取完整回答。
- **停止** —— 回答流式输出时会出现红色 **■** 按钮；点击即可停止生成。
- **来源** —— 每个回答都会以片的形式列出它参考的页面。点击来源片即可在新标签页打开该页面。
- **历史** —— 消息带有时间戳，轮次之间有分隔，因此较长的研究会话也能保持可读。

### 就选中文本提问

高亮页面上的任意文本，然后按 **Ctrl+Shift+A**（Mac：**Cmd+Shift+A**）。侧边面板会打开，
并在聊天输入框中预填你选中的内容（带引号）——准备好让你补充问题。

或者：选中文本 → 右键 → **向 JiuwenSwarm 询问「…」**

如需在固定页面中查找文本：选中文本 → 右键 → **在固定页面中搜索「…」**。面板的全文搜索
会打开并预填你的选中内容，立即执行。

### 总结页面

右键页面任意位置 → **总结此页面**。侧边面板会打开并预填一条总结请求。该页面会临时加入
本次请求的上下文。

### 会话模式

| 模式 | 适用场景 |
|---|---|
| **研究** | 多来源分析、交叉引用、事实核查 |
| **聊天** | 不带固定上下文的开放式对话 |
| **总结** | 提炼单个或一组页面 |
| **对比** | 两个或多个来源的并排对比 |

创建会话时或通过会话选择器下拉框可更改模式。

## 智能体页面操作

智能体不仅可以阅读，还可以与你打开的页面交互。当智能体判断这些操作有用时会自动触发——
无需单独的按钮。

智能体在页面上操作时，面板会显示内联状态片（例如「⚙ 正在页面上高亮一段文字…」），
让你知道它在做什么。

| 操作 | 效果 |
|---|---|
| **高亮文本** | 智能体用彩色覆盖层高亮它在当前标签页中引用的段落。 |
| **清除高亮** | 当对话继续或会话切换时，高亮会被移除。 |
| **滚动到元素** | 智能体将标签页滚动到你问题相关的某个区块。 |
| **填写表单** | 智能体按标签或字段名填写表单字段——适用于搜索页面、数据录入工具或研究门户。 |
| **截图** | 智能体将当前标签页的可见区域捕获为 PNG 以进行视觉分析。 |
| **读取 URL** | 智能体直接读取某个页面，无需用户手动打开并固定。 |
| **打开 URL** | 智能体在新标签页打开 URL——例如跟进被引用的来源。 |
| **固定页面** | 智能体可在相关时以编程方式将当前标签页固定到当前会话。 |

## 管理会话

### 切换会话
点击面板页头中的会话名称标签，打开会话选择器。点击任意会话即可切换。上下文栏会更新，
显示该会话的固定页面。

选择器**支持键盘**：打开时按 **↑ / ↓** 移动，**Enter** 选择，**Esc** 关闭。

### 重命名会话

点击 **⋯** → **重命名会话…**，为当前会话指定一个你喜欢的名称（或清空字段以重置）。
名称保存在浏览器本地，并显示在页头、会话选择器和弹窗中。

### 创建新会话

点击面板页头中的 **+ 新建**。会出现一个表单，包含：
- 名称字段
- **模式**选择器（研究 / 聊天 / 总结 / 对比）

### 导出会话

点击面板页头中的 **⋯**，然后选择导出格式：

- **导出 JSON** —— 下载一个包含会话元数据、所有固定页面和完整对话的 `.json` 文件。
- **导出 Markdown** —— 下载一个包含会话信息、完整对话以及每个固定页面文本预览的 `.md`
  文件。便于分享或归档到笔记应用中。

> 对话从扩展的本地聊天历史中导出。它涵盖该会话在此面板中发生过的情况。

### 固定所有打开的标签页

点击 **⋯** → **固定所有打开的标签页**，将当前窗口中的每个标签页一次性固定到当前会话
（不超过会话的固定页面上限）。

### 搜索固定页面

点击 **⋯** → **🔍 搜索固定页面**，在所有固定页面（标题、URL 和提取文本）中搜索。
输入即可搜索；结果即时显示。点击结果打开该页面。

### 离线重读

最近一次智能体回答会缓存在本地。如果在打开面板时 JiuwenSwarm 服务器不可达，会显示缓存
回答并带有「（缓存——服务器离线）」标签，让你仍可重读最近的研究。

### 页面的智能体视角

点击 **⋯** → **👁 智能体视角**，或右键任意页面 → **此页面的智能体视角**，阅读智能体从
当前页面实际提取的精确文本——一个干净、无干扰的视图，展示 JiuwenSwarm 真正读到的内容。
使用 **← 返回** 回到聊天。

### 会话持久化

会话存储在 JiuwenSwarm 服务器上，浏览器重启后仍然保留。它们与 JiuwenSwarm 网页端共享——
你在扩展中创建的任何会话都会出现在那里，反之亦然。固定页面元数据（提取文本、URL）存储在
Chrome 本地存储中，且因浏览器而异。

## 设置

通过弹窗（**⚙ 设置**）或右键工具栏图标 → **选项** 打开设置。

| 设置项 | 默认值 | 说明 |
|---|---|---|
| 主机 | 127.0.0.1 | JiuwenSwarm 服务器的 IP 或主机名 |
| 端口 | 19000 | WebSocket 端口 |
| 默认模式 | 研究 | 新建会话的模式 |
| 自动提取 | 开 | 打开面板时自动提取页面上下文 |
| 固定时自动总结 | 关 | 每次固定页面时请求一段简短总结 |

扩展会自动跟随操作系统的**浅色/深色**配色方案——没有单独的开关。整个界面（侧边面板、
弹窗和设置）支持**英文和简体中文**，与浏览器语言一致。

## 故障排查

### 红点 / 「未连接」

1. 确保 JiuwenSwarm 服务器正在运行。
2. 核对设置中的主机和端口与你的服务器配置一致。
3. 如果服务器在另一个端口，更新设置 → 保存 → 等待 5 秒。

连接断开时，面板会显示带**重试**按钮的**「与 JiuwenSwarm 失去连接」**横幅——点击即可
重连，无需刷新面板。

### 页面上下文为空或显示告警片

- 有些页面会阻止内容脚本（银行门户、Chrome 内部页面）。这些页面无法提取。
- SPA 页面（React、Next.js）可能需要片刻渲染。尝试在页面完全加载后取消固定再重新固定。
- 点击片上的 **↻** 重试按钮重新提取页面的当前状态。

### PDF 片没有文本

在 Chrome 内联打开的 PDF 页面无法由内容脚本提取。片会显示 **PDF** 徽标。使用 **↻**
重试按钮，它会通过服务器端 `read_pdf` 工具路由提取（如果你的 JiuwenSwarm 服务器上
有该工具）。

### 侧边面板打不开

Side Panel API 需要 Chrome 114+。如果使用的是较旧版本的 Chrome，请更新。

在不实现 Side Panel API 的 Chromium 系浏览器（360 安全浏览器、QQ 浏览器、搜狗浏览器）
上，扩展会自动改为以独立弹窗窗口打开面板。此模式下所有功能完全一致。

### 上下文被截断

页面上限为 120,000 字符。非常长的文档采用「头 + 尾」策略截断：保留预算的前 ~80% 和
最后 ~20%，既保留开头，也保留文档结尾的总结或结论。提取文本中会出现 `[...truncated...]`
标记。服务器也会强制执行自己的上下文窗口限制。

## 隐私

- 扩展将页面内容发送到你**配置的 JiuwenSwarm 服务器**，由该服务器转发给你选择的大模型提供商。本扩展不会联系其他任何服务。
- 会话存储在你的服务器上；卸载扩展只会删除本地存储的数据。

你可以随时从侧边面板查看此内容：**⋯** → **🔒 隐私**。
