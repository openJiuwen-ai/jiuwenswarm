# 安装指南

## 环境要求

| 依赖 | 版本 |
|---|---|
| Chrome（或 Chromium 系浏览器） | 114+（Side Panel API） |
| JiuwenSwarm 服务器 | 在任意端口运行（默认 19000） |
| Node.js | 18+（仅构建需要） |
| npm | 9+（仅构建需要） |

---

## 1. 构建扩展

克隆仓库并安装依赖：

```bash
cd jiuwenswarm-browser
npm install
```

然后构建：

```bash
npm run build
```

这会生成包含完整编译后扩展的 `dist/` 目录。

---

## 2. 加载到 Chrome（开发者模式）

1. 打开 Chrome 并访问 `chrome://extensions`。
2. 开启**开发者模式**（右上角开关）。
3. 点击**加载已解压的扩展程序**。
4. 选择本项目内的 `dist/` 目录。
5. JiuwenSwarm 图标出现在 Chrome 工具栏。

只要 Chrome 处于打开状态，扩展就会自动重连到服务器——无需手动重连。

---

## 3. 验证连接

1. 启动 JiuwenSwarm 服务器（默认：`ws://127.0.0.1:19000/ws`）。
2. 点击 JiuwenSwarm 工具栏图标——弹窗应显示**「已连接到本地服务器」**并带绿点。
3. 如果点是红色，请检查：
   - 服务器是否在运行？（`curl http://127.0.0.1:19000/health`）
   - 端口是否正确？打开**设置**（弹窗中的 ⚙）并核对主机/端口。

---

## 4. 配置服务器地址（可选）

扩展默认使用 `ws://127.0.0.1:19000`。如需更改：

1. 点击 JiuwenSwarm 图标 → **⚙ 设置**。
2. 更新**主机**和**端口**。
3. 点击**保存设置**。
4. 后台服务工作线程会在几秒内自动重连。

---

## 5. 固定侧边面板（推荐）

侧边面板是主要界面。为了让它始终可用：

1. 右键点击 JiuwenSwarm 工具栏图标。
2. 选择**固定到工具栏**（如果尚未固定）。
3. 在任意标签页按 **Ctrl+Shift+J**（Mac：**⌘+Shift+J**）打开/关闭面板。

> **首次运行：** 首次打开面板时，一段简短的上手引导会带你走一遍「固定 → 提问 → 操作」
> 流程。它只出现一次；可随时从 **⋯** 菜单重播。

---

## 6. 打包分发（可选）

如需生成适合 Chrome 应用商店或手动分发的 `.zip`：

```bash
npm run pack
```

输出：项目根目录下的 `jiuwenswarm-browser-<version>.zip`。

---

## 更新

拉取新的源代码后：

```bash
npm install       # 获取任何新依赖
npm run build     # 重新构建 dist/
```

然后进入 `chrome://extensions`，点击 JiuwenSwarm 卡片上的 **↻ 重新加载** 按钮。
无需重新添加扩展。

---

## 卸载

进入 `chrome://extensions`，找到 JiuwenSwarm 并点击**移除**。
本地存储的数据（固定页面元数据、设置）会被删除。会话存储在 JiuwenSwarm 服务器上，
不受影响——仍可通过网页端访问。
