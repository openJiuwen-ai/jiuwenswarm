# JiuwenSwarm 浏览器扩展

一款 Chromium 扩展，让 JiuwenSwarm AI 智能体常驻于你正在阅读的任意网页旁。
将多个页面固定（Pin）到研究会话中，跨来源提问，让智能体在你所看到的内容上直接操作——
全程无需离开浏览器。

**需要：** JiuwenSwarm 服务器（默认 `ws://127.0.0.1:19000`）。

**浏览器支持：** Chrome 114+（Side Panel API）。在不支持 Side Panel API 的 Chromium
系浏览器（360 安全浏览器、QQ 浏览器、搜狗浏览器）上，面板会自动以弹窗方式打开——
所有功能完全一致。

---

## 特性

- **9 种页面类型适配器** —— GitHub、arXiv、SEC EDGAR、PubMed、Wikipedia、YouTube、
  Twitter/X、Hacker News，以及用于其他一切页面的 Readability.js 兜底
- **多标签研究会话** —— 从多个标签页固定页面；智能体会收到全部提取内容，作为一个统一的上下文块
- **会话统一** —— 在扩展中创建的会话会出现在 JiuwenSwarm 网页端，反之亦然；服务器是唯一数据源
- **会话导出** —— 导出为 JSON 或人类可读的 Markdown，包含完整对话
- **会话重命名** —— 可为你指定的任意会话命名（⋯ → 重命名会话…），本地保存
- **浏览器原生智能体工具** —— 智能体可以高亮被引用的段落、滚动到指定区块、填写表单字段、
  截图、读取指定 URL、打开新标签页，并可编程地固定页面——无需用户手动触发这些操作
- **提取质量信号** —— 每个片（chip）显示字符数、低产出页面告警、PDF 徽标，以及提取失败时的重试按钮
- **丰富聊天界面** —— 聊天在专用的 `chat.html` webview 中渲染
- **键盘快捷键** —— 打开/关闭面板、固定当前标签页、就选中内容提问
- **右键上下文菜单** —— 就选中内容提问、固定页面、总结页面
- **SPA 导航检测** —— URL 变化时无需完整刷新即可重新提取上下文
- **设置** —— 可配置服务器主机、端口、默认会话模式、行为开关
- **弹窗回退** —— 在无 `chrome.sidePanel` 的 Chromium 浏览器（国产浏览器、未来的 Firefox
  版本）上，在独立弹窗中打开面板；所有功能不变
- **丰富可读的聊天** —— 智能体回答以 Markdown 渲染（代码、列表、链接、标题），并带有一键
  **复制**，生成时可点 **停止** 按钮
- **来源引用** —— 每个回答都列出其**来源**（被固定的页面）；点击即可在新标签页打开
- **聊天历史** —— 消息带有时间戳，轮次之间有分隔，便于阅读
- **批量固定** —— 一次性把当前窗口所有打开的标签页固定到会话（⋯ 菜单）
- **全文搜索** —— 从 ⋯ 菜单在全部固定页面中搜索
- **智能体视角** —— 查看智能体实际读取的内容：从 ⋯ 菜单或右键菜单以清爽视图打开当前页面的提取文本
- **离线重读** —— 最近一次智能体回答会被缓存，服务器不可达时仍可查看
- **固定时自动总结** —— 可选设置，每次固定时请求一段简短总结
- **应用内隐私说明** —— ⋯ 菜单中的 **🔒 隐私** 项，明确说明哪些留在本地、哪些发送到你的服务器
- **上手引导** —— 简短的首次运行浮层教授「固定 → 提问 → 操作」流程；可随时从 ⋯ 菜单重播
- **永不死路** —— 无会话时会出现内联的 **+ 创建会话** 按钮；在没有会话时固定或提问会打开
  表单，而不是静默失败
- **输入前提示** —— 一键片（「总结此页面」，以及固定两个页面后出现的「比较所固定的页面」）
  在首次提问前填补空白
- **固定反馈** —— 每次固定都有 toast 和工具栏徽标（固定数量）确认；工具栏徽标追踪当前会话的固定页面
- **取消固定的撤销** —— 取消固定页面会显示**撤销** toast，方便反悔
- **重排固定页面** —— 每个片上的 ◀ ▶ 按钮用于设置上下文优先级（顺序很重要）
- **「我的上下文里有什么」** —— 点击任一固定片可预览其提取文本
- **智能体操作可见性** —— 当智能体高亮、滚动、填写表单或截图时，内联状态片会告诉你它正在页面上做什么
- **连接恢复** —— 服务器不可达时出现带**重试**按钮的横幅，并以通俗语言重新表述错误
- **深色模式** —— 跟随操作系统配色，覆盖面板、弹窗和设置
- **思考指示** —— 智能体组织回复时显示脉动骨架动画
- **键盘优先** —— 会话选择器和固定页面片可用方向键导航
- **多语言** —— 完整界面支持英文和简体中文（根据浏览器自动检测）

## 快速开始

```bash
npm install
npm run build
```

然后在 `chrome://extensions` 中以「加载已解压的扩展程序」加载 `dist/` 目录。

完整步骤参见 [浏览器扩展安装](浏览器扩展安装.md)。

## 开发

```bash
npm run dev          # 监听模式构建
npm run type-check   # TypeScript 类型检查
npm run lint         # ESLint
npm run test         # 单元测试（Vitest）
npm run build        # 生产构建
```

## 项目结构

```
src/
├── shared/       常量、类型、协议、存储、日志
├── background/   服务工作线程：WsClient、SessionManager、ContextCache、
│                 TabWatcher、ContextMenu、ToolDispatcher
├── content/      注入脚本：Extractor、PageTypeDetector、
│                 adapters（GitHub / arXiv / SEC / PubMed / Wikipedia /
│                 YouTube / Twitter / HackerNews / generic）、
│                 SelectionMonitor、Annotator、FormAssist
├── sidepanel/    侧边面板 UI：index.ts（聊天 + 装配）与聚焦模块
│                 ChatBridge、SessionPicker、ContextBar、SessionExporter、
│                 chat、markdown、reader、tour、privacy、search
├── popup/        工具栏弹窗：连接状态、快捷操作
├── options/      设置页面：主机/端口、行为开关
└── webview/      chat.html（webview 聊天界面）
```
