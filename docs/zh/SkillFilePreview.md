# Skill 工作副本文件列表与文本预览

本说明对应 `jiuwenswarm/server/runtime/skill/skill_files.py`，描述文件预览行为和排障边界，不改变 Skill 的安装或执行权限。

## 文件树

文件列表按工作副本的相对路径排序，忽略符号链接和根级 `.archive/`。目录内存在指向外部或不存在目标的符号链接时，应跳过链接，不应使正常文件列表整体失败。

排序使用未解析的相对路径；之后仍执行原有的真实路径包含关系检查。此修复不放开跨目录访问，也不承诺在文件被并发修改时提供文件系统快照。若有文件系统权限或目录遍历错误，仍可能需要检查工作副本状态。

## 文本预览

默认字节上限为 512 KiB，按原始文件字节计算，包含 UTF-8 BOM。接受普通 UTF-8 和带 BOM 的 UTF-8，显示时去掉开头的 BOM。不会转换原文件，不改变 CRLF/LF 换行内容。

不可预览的二进制、无效 UTF-8 或超限文本返回 `None`，由调用方选择下载等回退方式。缺失或不可读取文件保留 `SKILL_NOT_FOUND` 业务错误；负数 `max_bytes` 抛出 `ValueError`。上限为零时仅允许空文件返回空字符串。

文件大小预检查之后仍进行有界读取，最多读取 `max_bytes + 1` 字节。这避免持续写入的日志在 stat 和读取之间增长时被整文件读入内存。它不提供全文件类型识别；原有 NUL 检查仍只检查前 8192 字节，不支持 UTF-16 或任意编码自动探测。

## 验证

```text
python -m pytest tests/unit_tests/agentserver/test_skill_files_preview.py -q
```

测试包括正常排序、隐藏归档、外部及悬空符号链接、BOM、错误编码、精确字节边界、增长文件、零/负上限及缺失文件。符号链接测试需要系统允许创建符号链接；不支持时明确 skip，而不是声称验证通过。
