# 重试失败的回复

在单 Agent 对话中，模型请求失败后，错误消息下方可显示“重试”。重试使用新的请求 ID 再次发送原始请求，保留原提示词、模型、已持久化的附件及请求配置，不使用输入区后来修改的选项。

仅最新提交的轮次可重试。会话处理期间按钮禁用，快速重复点击不会产生并发重试。再次失败后仍可重试，成功回复后重试入口消失。原用户消息保留，新回复以流式方式显示。重试使用服务器已有的 `log_as_user: false` 选项，刷新历史后不会新增重复的用户提示词。未完成的回复及错误保留在当前页面，恢复时生成独立的新回复。

仅关联到原请求的服务器 `chat.error` 事件提供重试。首次提交被拒绝或超时时，是否接收并写入历史尚不确定，因此不提供整轮重试。

执行过工具的轮次、团队模式、SwarmFlow 及目标补充约束请求不支持整轮重试，以免重复执行操作。本功能不会回滚外部系统，也不会从工具检查点恢复。

请求快照仅保存在当前页面内存中。刷新页面或恢复历史后，重试可能不可用，此时请手动重新发送提示词。快照在 30 分钟后过期；同会话的新提交会替换旧快照；跨会话最多保留 40 条；删除会话会清理对应快照。

## 开发验证

在 `jiuwenswarm/channels/web/frontend` 运行 `npm run test:chat-retry`。

手动验证时，配置本地兼容 OpenAI 格式的模拟接口，选择 Agent 模式。先持续返回 HTTP 503，待错误出现后快速点击两次重试，确认只发出一个新的 `chat.send` 请求（模型 SDK 的 HTTP 自动重试可能产生多次 HTTP 请求）。保持 503 验证再次失败，然后切换为有效的流式回复，确认重试成功且会话恢复空闲。

还需验证附件、失败后切换模型、切换会话和刷新页面。使用本地模拟服务即可，无需真实模型 API。
