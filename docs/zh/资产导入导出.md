# 资产导入导出

> **目标**：帮助用户了解专家与专家团资产包的统一导出与导入能力，掌握资产包的导出、跨环境导入与错误提示的处理方法。
>
> **英文版：** [English Version](../en/AssetExportImport.md)

---

## 1. 概述

统一资产导入导出把本地的**专家（agent_template）**与**专家团（agent_group）**打包为标准 `.zip` 资产包，用于在不同环境（开发机、测试机、生产部署）之间备份、迁移与分发。

### 1.1 什么是资产包

资产包是一个**单层根目录**结构的 `.zip` 压缩包：根目录名即资产 id，目录内的 `manifest.json` 清单描述资产的类型、名称与版本。

```text
expert.demo.zip
└── expert.demo/
    ├── manifest.json
    ├── persona/…
    └── …
```

- 导出时系统自动按该结构打包，下载文件名为 `<名称>.zip` 或 `<名称>-<version>.zip`（清单声明了版本时携带版本后缀）；`<名称>` 取界面显示名，缺省时回退资产 id。包内顶层目录名始终为资产 id，与下载文件名无关；
- 导入时系统先安全解包，再按根目录清单完成校验与落库。

### 1.2 支持的资产类型

| 资产类型 | 导出 | 导入 | 导入后行为 |
|---------|------|------|-----------|
| 专家（agent_template） | 支持 | 支持 | 导入后自动接续安装流程（见 3.3） |
| 专家团（agent_group） | 支持 | 支持 | 导入即安装，直接进入「我的」列表 |

> 💡 **提示**：技能、插件等其他资产类型请使用各自页面的既有上传/安装入口。

### 1.3 适用场景

- 把开发环境调试好的专家或专家团迁移到生产环境；
- 系统升级或重装前，备份本地创建的资产；
- 将一套专家团分发给同事，对方导入后即可使用。

## 2. 导出资产

### 2.1 导出入口与可见条件

打开专家或专家团详情页，在操作区点击**导出**按钮，系统生成资产包并触发下载：

- **桌面端**：弹出保存对话框，选择本地目录保存；
- **浏览器**：直接开始下载，或提示选择保存位置。

按钮可见性与服务端可导出范围一致：

| 资产 | 显示导出按钮的条件 |
|------|------------------|
| 专家 | 本地创建的包，或已安装的内置/Hub 副本 |
| 专家团 | 除 Hub 未安装资产外均可见（含未安装的本地/内置包） |

> ⚠️ **注意**：未安装的货架与 Hub 资产在本地没有可打包的物料，因此不显示导出按钮。

### 2.2 导出时的内容处理

导出走统一的安全打包，会自动执行以下处理：

- **剔除冗余目录**：`.git`、`.archive`、`__pycache__`、`.pytest_cache`、`node_modules`、`out`、`.venv`，以及 `.DS_Store` 等杂项文件；
- **剔除敏感文件**：私钥（`id_rsa`、`id_ed25519`）、`credentials.json`、`token.json` / `tokens.json`、`*.key` / `*.p12` / `*.pfx` 与真实 `.env` 文件；仅放行 `.env.example` / `.env.template`，且其内容不得包含明文密钥或带账号密码的 URL；
- **校验体量上限**：压缩包 ≤50MB、单文件 ≤64MB、解压后总量 ≤512MB、文件数 ≤10000、目录深度 ≤32，超限导出失败并提示。

导出产生的下载链接为**短时效**（约 10 分钟），请及时完成保存。

## 3. 导入资产

### 3.1 导入入口

导入复用既有的**上传文件创建**入口，不另设菜单项：在**专家管理**页打开**创建**菜单，选择**上传文件创建**；专家视图下导入专家包，切换到专家团视图后同名入口导入专家团包。

对话框支持**点击选择**本地 `.zip` 资产包，桌面端还支持拖拽文件进窗口；其他格式的文件不会被接受。

### 3.2 导入流程

1. 选定文件后由服务端就地读取并安全解包：校验包结构与清单，拒绝符号链接与路径穿越条目；
2. 校验通过后落库，返回资产 id；
3. 页面提示导入结果并切换到「我的」列表。

### 3.3 导入后的行为

两类资产导入后的行为不同：

- **专家团**：导入即安装，成功后直接出现在专家团「我的」列表；若安装失败，导入保留并提示失败原因，可在详情页重试安装；
- **专家**：导入后自动接续安装流程；安装失败会回滚本次导入，不留下半导入的专家，对话框内显示失败原因，可直接重试；若专家依赖的连接器需要授权，会弹出授权引导。

若资产声明的连接器在当前环境尚未就绪，安装流程会给出授权引导。请在**扩展**页完成连接器授权后再使用相关能力。

### 3.4 导入不覆盖既有资产

- 同 id 资产已存在于本地 → 拒绝导入，提示先删除或改名；
- 与系统内置资产同 id → 拒绝导入，内置资产不可覆盖；
- 专家团显示名与既有专家团重复 → 按同名冲突拒绝。

## 4. 错误提示速查

表中提示为导出链路的统一错误文案；导入失败时对话框内会就地显示对应的失败原因，含义与处理建议相同。

| 提示 | 含义 | 处理建议 |
|------|------|---------|
| 资产或指定版本不存在 | 导出目标已被删除，或指定的版本不存在 | 确认资产存在且已安装后重新导出 |
| 未安装或受限的资产不可导出 | 资产类型未接入导出，或未安装且无本地物料 | 先完成安装，再导出 |
| 资产包无效：缺少清单文件或包结构不合法 | zip 不是单层根目录结构、缺少 manifest.json 或类型无法识别 | 使用统一导出生成的资产包，勿手工改动包结构 |
| 资产包包含符号链接或非法路径，已拒绝 | 包内含 symlink 或路径穿越条目 | 移除相关条目后重新打包 |
| 资产文件中检测到明文敏感凭证，请清理后重试 | 文件内容命中凭证扫描 | 清理明文密钥后重试 |
| 文件数量、单文件或压缩包体积超出限制 | 体量超过上限（见 2.2） | 精简包内容后重试 |
| 同 id 资产已存在，不支持覆盖，请先删除或改名 | 本地已有同名资产 | 先删除既有资产，或修改包内资产 id |
| 与系统内置资产冲突，不可覆盖 | 与内置资产同名 | 修改包内资产 id |

## 5. 常见问题

### 5.1 详情页没有导出按钮

**问题描述**：专家或专家团详情页操作区看不到「导出」按钮。

**解决方案**：对照 2.1 的可见条件——专家仅本地创建的包或已安装的副本可导出；专家团的 Hub 未安装资产不可导出。请先完成安装，再回到详情页操作。

### 5.2 导入提示「资产包无效」

**问题描述**：上传 .zip 后提示资产包无效或无法识别类型。

**解决方案**：导入只接受**由统一导出生成**、带 `manifest.json` 的资产包。请勿手工压缩任意目录后导入；迁移技能包请使用技能页面的既有上传入口。

### 5.3 目标环境已有同名资产

**问题描述**：导入时提示同 id 资产已存在。

**解决方案**：导入不支持覆盖。需要替换时，先在目标环境删除既有同名资产再导入；也可以在源环境修改资产 id 后重新导出。

### 5.4 导入成功后有连接器待授权

**问题描述**：导入成功，安装流程提示存在待授权连接器。

**解决方案**：在**扩展**页完成对应连接器的授权。专家安装失败会回滚导入，完成授权后重新导入即可；专家团导入即已安装，完成连接器授权后成员即可正常调用。
