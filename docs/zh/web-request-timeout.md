# Web 默认请求超时

Web 默认等待请求响应的时间为 15 秒。可在部署工具的 `.env.custom` 中设置秒数：

```dotenv
WEB_REQUEST_TIMEOUT_SECONDS=60
```

更新部署工具及支持该配置的 Web 镜像后，重新部署 Web 并刷新浏览器页面即可生效；以后调整该值无需重新编译前端。多个 Web 副本应使用相同配置。

部署工具将配置传入 Web 容器，Web 在返回入口 HTML 时注入浏览器。Nginx 镜像和 Python Web 服务使用同一参数。直接启动 Python Web 时也可以设置同名环境变量。

未设置或留空时仍为 15 秒。配置必须为 1 至 2147483 的整数，单位为秒；非法值回退到 15 秒并记录警告。上限用于防止浏览器计时器溢出，0 不表示无限等待。

此值只替换 HTTP/WebSocket 客户端原有的默认请求超时。调用方明确指定的接口超时仍优先，例如技能列表等接口已有的独立超时。

HTTP 聊天收到响应头后会清除该定时器，因此本参数不限制后续 SSE 流的总时长，也不是模型生成的总时长限制。前置代理和后端服务的超时仍由各自配置决定。
