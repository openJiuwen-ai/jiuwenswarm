# RSI 优化状态与结果

优化详情中的“迭代轮次”表示引擎报告的完成进度。正在执行的第 N 轮可以先出现在画布中，完成后再计入汇总；Harness 一轮中的局部候选尝试不会分别增加轮次，程序被提前丢弃的候选也不等同于完成一次评测。

论文和 Harness 在统计可用时展示剪枝数。剪枝数优先使用引擎报告，未提供时由树中已剪枝节点补齐；未知时不展示，未采纳和进行中节点不计入剪枝。组合评测只适用于 Harness，论文和程序不展示这一列。

任务完成、失败、终止或暂停后，详情轮询会同步侧栏状态并停止运行点闪动。结果汇总使用最终快照，避免旧的实时轮次覆盖结果。

AgentServer 重启后，历史论文任务仍能从已保存的快照读取 token 总量、进度、优化树和最优产物。旧快照未记录用量时，token 栏显示 `--`。

任务失败时，可点击失败状态旁的图标查看接口返回的失败原因。节点详情还提供本轮未采用或剪枝的原因。历史任务若仅保存了概括性原因，界面无法恢复未保存的模型错误原文。
