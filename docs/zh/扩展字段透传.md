# 请求级扩展字段透传

## 功能说明

扩展字段用于把集成方约定的少量请求级上下文，从 User Web 请求透传到 Agent Rail。字段只在白名单中声明后生效，不参与登录认证、身份授权或路由选择。

支持两种 User Web 入站方式：

- HTTP/SSE：从请求 Header 读取白名单字段；
- WebSocket：从握手 URL Query 读取白名单字段。

两条链路在 Gateway 内统一写入 `Message.metadata.ext`。Gateway 使用 HTTP/SSE 调用 AgentServer 时，将该对象编码到内部 Header `X-Jiuwenswarm-Request-Ext`；AgentServer 解码后恢复到 `AgentRequest.metadata.ext`，Rail 通过 `get_ext()` 读取。

```text
HTTP Header / WebSocket Query
            ↓ 白名单过滤
Gateway Message.metadata.ext
            ↓ Base64URL(JSON)
X-Jiuwenswarm-Request-Ext
            ↓ AgentServer 解码
AgentRequest.metadata.ext
            ↓ 请求级 ContextVar
Rail get_ext()
```

## 部署配置

在部署工具 `.env.custom` 中配置需要透传的字段名，多个字段使用英文逗号分隔：

```dotenv
JIUWENSWARM_REQUEST_EXT_FORWARD_HEADERS="X-Tenant-Id,X-Trace-Id"
```

空值表示关闭扩展字段透传。部署脚本会将该变量写入 Gateway 的运行环境；AgentServer 无需新增环境变量。

HTTP/SSE 示例：

```http
X-Tenant-Id: tenant-a
X-Trace-Id: trace-001
```

WebSocket 示例：

```text
/ws?X-Tenant-Id=tenant-a&X-Trace-Id=trace-001
```

Rail 读取示例：

```python
from jiuwenswarm.common.request_ext import get_ext

request_ext = get_ext()
tenant_id = request_ext.get("X-Tenant-Id")
```

## 边界与安全约束

- 扩展字段值来自请求方，业务代码不得将其直接当作可信身份或授权依据；
- `X-Jiuwenswarm-Request-Ext` 是 Gateway 与 AgentServer 之间的内部传输头，不应由外部客户端直接构造；
- Base64URL 仅用于安全承载 Unicode 和特殊字符，不提供加密或签名；
- 扩展 JSON 编码前最大为 4 KiB，编码后的内部 Header 最大为 6 KiB；
- 非法 Base64URL、非 JSON 对象或超限载荷由 AgentServer 返回 HTTP 400；
- 请求结束后 AgentServer 会清理请求级上下文，避免扩展字段串到其他请求。
