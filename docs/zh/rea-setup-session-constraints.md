## 页面结构

- “逆向”是左侧一级导航，不使用当前聊天页里的临时入口替代。
- 安装页由页头、顶部安装进度卡、基础环境分组、增强能力分组和任务指南组成。
- 基础环境只包含 Node.js/npm/npx、REA 运行时、REA MCP 三项。
- 增强能力按能力卡展示，卡片内部成员是工具或运行组件，不在外层逐个铺开。
- 整张能力卡只有一个成员时，卡片状态和操作可以落在该成员上。

## 安装与检测

- 基础环境的“检测”只检测基础能力，不扫描增强能力。
- 增强能力的“检测”可以检测全部增强能力。
- 安装任务进行中，除已经明确安装完成或明确失败的项目外，其余尚未确认的项目统一显示“安装中”。
- 不显示“检测中”“需检测”“等待检测”等中间状态；这些状态统一归入“安装中”。
- 安装中的图标使用高保真中的两个静态青色横条，不使用转圈动画。
- 每个增强组件结束后立即刷新该组件对应能力卡的状态，无论安装成功、需要配置还是失败；不能等全部组件结束后才统一刷新。
- 剩余时间必须反映整个安装任务，不能把单个下载阶段的“2 秒”直接当成整个安装的剩余时间。显示值需要稳定更新，避免每轮轮询跳动。

## 分组状态

- 分组总状态只在安装结束且至少有一个安装结果时显示。
- 全部可用：显示绿色圆圈加勾，文案为“已完成”。
- 部分可用：显示蓝色圆圈加勾，文案为“部分安装”。
- 安装过程中不显示分组总状态。
- 一个项目都没有安装时，不显示分组总状态。
- 增强能力分组的“已安装”数量要把“部分安装”的能力卡也计入，保证数量与用户可见的已落盘状态一致。
- 基础环境分组的计数不采用增强能力的部分安装计数规则。

## 能力卡状态与操作

| 卡片状态 | 高保真图标 | 外部操作 |
|---|---|---|
| 可用 | 仅绿色空心圆圈，圆圈内没有勾 | 不显示“配置” |
| 安装中 | 两个静态青色横条 | 不显示“配置” |
| 需配置 | 橙色空心警告三角和感叹号 | 单成员卡显示“配置” |
| 部分可用 | 仅蓝色空心圆圈，圆圈内没有勾 | 显示“查看说明” |
| 当前不适用 | 灰色空心圆圈 | 显示“查看说明” |
| 安装失败 | 失败状态图标 | 显示“查看说明” |

- 多成员能力卡中只要有成员可用、同时还有成员需要配置，整张卡显示“部分可用”，外部操作为“查看说明”。
- 多成员能力卡的“查看说明”只展示能力说明和只读成员状态，不在弹窗内提供配置控件。
- 多成员能力卡即使没有可用成员，只要内部存在需要配置的成员，也不在外层直接展开多个配置入口；使用卡片级状态和说明入口。
- 只有单成员能力卡需要配置时，外层才直接显示“配置”。
- 明确不适用的卡仍显示“查看说明”，不能显示“配置”。
