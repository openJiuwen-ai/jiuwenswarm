# 负责人配置文件

仓库根目录下的 `CODEREVIEWER`、`COMMITTER`、`USER.json` 三个文件共同配置
PR 的检视人、合并人分派以及飞书任务通知。仓库内没有代码读取它们，由外部工具消费。

## CODEREVIEWER：检视负责人映射

- 每行一条规则：`<路径> <账号>[,<账号>...]`，`#` 开头为注释。
- 路径以 `/` 结尾表示整个目录，否则表示单个文件。
- 不支持按行号定义负责人；同一文件有多名负责人时，用逗号写在同一行。

## COMMITTER：合并负责人映射

- 行格式同 `CODEREVIEWER`，`/*` 表示整个仓库。
- 列出的账号彼此平级，没有主合并人，合并任务分别派发给每个人。

## USER.json：全量成员名单

- 记录所有成员，包括暂未担任检视人或合并人的贡献者。
- key 为拼音账号，即上面两个文件中使用的账号；value 为
  `{"gitcode": ..., "feishu": ...}`：
  - `gitcode`：该成员提交代码使用的邮箱，一般为华为邮箱。
  - `feishu`：发送通知使用的飞书 ID。
- 两个字段在未知时都可以留空。

## 约束

- `CODEREVIEWER` 和 `COMMITTER` 中出现的每个账号都必须在 `USER.json` 中登记；
  新增成员时先在 `USER.json` 登记。
