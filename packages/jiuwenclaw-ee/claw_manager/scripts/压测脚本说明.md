# 压测脚本说明

目录：`packages/jiuwenclaw-ee/claw_manager/scripts/`

当前主压测入口是 **`single_pod_n_concurrency_test.py`**：单 AgentServer Pod、N 路会话数据面压测。同目录还有底层发送实现、Mock LLM、作文附件。

| 文件 | 作用 |
|---|---|
| `single_pod_n_concurrency_test.py` | **当前压测脚本**。1 个 Pod / 1 个 Bot，N 个 user + N 个 session，齐发 `chat.send` |
| `enterprise_runtime_concurrent_test.py` | WebSocket 发送、步骤判定、权限自动放行、下载交付文件。单 Pod 脚本会直接复用它 |
| `mock_llm_server.py` | OpenAI 兼容 Mock LLM。`--flow loadtest` 时需 `--profile loadtest` |
| `童趣的春天.md` | loadtest 第 3 步（file）默认上传的作文附件 |

## 当前压测脚本做什么

`single_pod_n_concurrency_test.py` 对齐 `single-pod-n-concurrency` 的 SP-02 / SP-12 主路径，经 WebChannel WebSocket 发真实 `chat.send`，验证同一 AgentServer 上 N 路会话能否同时被接受并跑完。

### 身份模型

每轮自动生成 8 位 hex `run_id`（也可用 `--run-id` 固定），避免复用上一轮 MySQL checkpoint / 工作区：

| 维度 | 规则 | 默认示例（N=10，run_id=`f48a37c0`） |
|---|---|---|
| Pod / AgentServer | 1 个 | 同一 `group_id` |
| Bot | 1 个 | `--bot-id`，须是 Manager 里已配置的智能体 |
| 工作区 | N 个 | `u_1_<run>` … `u_N_<run>` |
| 执行器 / 会话 | N 个 | `sess_1_<run>` … `sess_N_<run>` |

`session_id` 必须是 `sess_*` 这种下划线形式，现成 Mock LLM 才能按会话拆状态。

### 两种流程（`--flow`）

**`single`（默认）**：每路只发一条短消息，用来确认链路通、Mock 能回。默认文案：

```text
请只回复：mock-ok。不要调用任何工具，不要提问。
```

**`loadtest`**：每路在同一 `session_id` 里依次走 4 步，须配合 `mock_llm_server.py --profile loadtest`：

1. **travel**：写一篇「旅行的意义」长文并保存为 txt 发回
2. **skill**：制作北京 3 日游攻略并保存为 markdown 发回（Deep：`todo` / `write_file` / `send_file_to_user`；不安装 skillnet，不调 `skill_step` / `free_search` / `skill_complete`）
3. **file**：上传 `童趣的春天.md`，扩写到约 6000 字后发回；脚本把交付文件下到本目录 `download_YYYYMMDD_HHMMSS/`
4. **cron**：创建「1 分钟后提醒喝水」定时任务；创建确认不算完成，须等到投递文案（如「喝水时间到啦」）

脚本默认会自动放行权限 / 追问弹窗（`chat.ask_user_question`）。`Ctrl+C` 时会对已接受未完成的会话发 `chat.interrupt`（`intent=cancel`），只关 WebSocket 不会停掉 AgentServer 上的任务。

### 成功判定

每路须 `accepted=True` 且整轮跑完（`final=True`）。Mock loadtest 若上一轮工具结果失败，会停止后续工具并打 `[mock-fail-fast]`，该步不会再靠本地假攻略交差。结束时会断言：

- `distinct_user_id == N`
- `distinct_session_id == N`
- `failed == 0`

进程退出码 `0` 表示全部成功；有失败为 `1`；参数非法为 `2`；`Ctrl+C` 为 `130`。

日志里会看到：

```text
[result] total=10 completed=10 failed=0 elapsed=...
accept_ms: avg=... min=... max=...
total_ms: avg=... min=... max=...
```

## 怎么执行

在 **jiuwenswarm 仓库根目录** 执行。依赖仓库 `.venv` 里的 `websockets`。

### 1. 环境准备

- Web / Gateway 已起来，本环境默认 NodePort：`192.168.1.90:30086`，WebSocket 路径 `/ws`
- `--bot-id` 必须是 Manager 里真实存在的智能体 ID，不要用默认占位 `bot_main`
- `--flow loadtest` 时，AgentServer 的模型要指向 Mock LLM，例如：

```text
API_BASE=http://<mock-llm-host>:19999/v1
API_KEY=mock-key
MODEL_PROVIDER=OpenAI
MODEL_NAME=mock-model
LLM_SSL_VERIFY=false
```

Mock LLM 先起（需对外监听时用 `0.0.0.0`）：

```bash
.venv/bin/python packages/jiuwenclaw-ee/claw_manager/scripts/mock_llm_server.py \
    --host 0.0.0.0 --port 19999 --profile loadtest --novel-chars 32000
```

`--flow single` 可用 `--profile e2e`。

### 2. 当前环境：10 路完整 loadtest（已验证）

```bash
cd /root/mz/jiuwenswarm

.venv/bin/python packages/jiuwenclaw-ee/claw_manager/scripts/single_pod_n_concurrency_test.py \
    --host 192.168.1.90 --web-port 30086 \
    --concurrency 10 \
    --flow loadtest \
    --bot-id 6e79b0e9-829c-48d8-8027-263a7622983d
```

等价写法（直接给完整 WS 地址）：

```bash
.venv/bin/python packages/jiuwenclaw-ee/claw_manager/scripts/single_pod_n_concurrency_test.py \
    --ws-url ws://192.168.1.90:30086/ws \
    --concurrency 10 \
    --flow loadtest \
    --bot-id 6e79b0e9-829c-48d8-8027-263a7622983d
```

### 3. 冒烟：只发一条短消息

```bash
.venv/bin/python packages/jiuwenclaw-ee/claw_manager/scripts/single_pod_n_concurrency_test.py \
    --host 192.168.1.90 --web-port 30086 \
    --concurrency 8 \
    --flow single \
    --bot-id 6e79b0e9-829c-48d8-8027-263a7622983d
```

### 4. 常用参数

| 参数 | 默认 | 说明 |
|---|---|---|
| `--host` | `192.168.1.90` | Gateway / Web 节点地址 |
| `--web-port` | `30086` | Web NodePort |
| `--ws-path` | `/ws` | WebSocket 路径 |
| `--ws-url` | 无 | 完整 `ws://` / `wss://`，设置后忽略 host/port |
| `--concurrency` / `-n` | `8` | 并发会话数 |
| `--group-id` | `load-g` | 全员同一 group |
| `--bot-id` | `bot_main` | 全员同一 bot，须改成真实 ID |
| `--user-prefix` | `u` | user_id = `{prefix}_{i}_{run}` |
| `--session-prefix` | `sess` | session_id = `{prefix}_{i}_{run}`，须保持 `sess` |
| `--run-id` | 自动 8 位 hex | 传入则可复现同一批 user/session |
| `--flow` | `single` | `single` 或 `loadtest` |
| `--content` | 见上文短消息 | 仅 `--flow single` 使用 |
| `--mode` | `agent` | 运行模式。历史 `agent.fast` 会归一成 `agent`（DeepAdapter） |
| `--accept-timeout` | `60` | 等待 `chat.send` 被接受（秒） |
| `--final-timeout` | `180` | `single` 整轮超时（秒） |
| `--loadtest-final-timeout` | `7200` | `loadtest` 整轮超时（秒） |
| `--cron-delivery-timeout` | `120` | cron 创建后等待到点投递（秒） |
| `--essay-file` | 同目录 `童趣的春天.md` | loadtest file 步附件 |
| `--accept-only` | 关 | 只等 Gateway 接受，不等 Agent 跑完 |
| `--no-auto-allow` | 关 | 禁用权限弹窗自动放行 |
| `--ws-event-log` | 关 | 打印每路 WS event 名 |

改并发路数只改 `--concurrency`，例如 20 路：

```bash
.venv/bin/python packages/jiuwenclaw-ee/claw_manager/scripts/single_pod_n_concurrency_test.py \
    --host 192.168.1.90 --web-port 30086 \
    --concurrency 20 \
    --flow loadtest \
    --bot-id 6e79b0e9-829c-48d8-8027-263a7622983d
```

### 5. 产物与日志

- 标准输出带毫秒时间戳：`[plan]` / `[accepted]` / `[step-done]` / `[done]` / `[requests]` / `[result]`
- loadtest 的 file 步交付文件：`packages/jiuwenclaw-ee/claw_manager/scripts/download_YYYYMMDD_HHMMSS/`，文件名带路号，例如 `童趣的春天_扩写版_00.md`
