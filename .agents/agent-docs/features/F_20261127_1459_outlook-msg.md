# Web 会话读取 Outlook MSG 邮件

个人版和企业版共用的 Web 选择器接受 `.msg`。沿用 [EML 功能](F_20261126_2117_enterprise-eml.md) 的文档上传和会话权限，Agent 通过同一个 `read_email` 工具读取最多 20 MiB 的邮件原件。在受支持的 Linux 或 macOS 服务端，使用 `python-oxmsg` 和 `olefile` 读取 Outlook 的复合文件结构与 MAPI 属性。MSG 与 EML 共用邮件头、正文、附件名及截断标记的输出格式。

MSG 正文支持纯文本和 HTML。随信附件仅提供名称。纯 RTF 正文、加密正文和联系人、日历项、任务等 Outlook 对象不在本期读取范围内。

复检时用 Apache POI 的普通和 Unicode 邮件样本验证了正文与附件名，繁体中文样本的 948 个正文字符与按 CP950 解码的原始正文一致。独立写入器生成的样本覆盖混合代码页、HTML 正文、纯 RTF 提示和任务拒绝。解析器只打开邮件字段和附件名称所需的流，以属性表和目录项上限约束解析工作量。

macOS 后端 155 项定向用例全部通过，覆盖 MSG、已有 EML、工具注册、会话和附件回归。Linux 上从个人版分块上传和企业版模拟 OBS 导入两条入口读取邮件，均验证了恰好 20 MiB 时可读、再多 1 字节时提示超限。

双版输入框用例在同一次选择中上传 EML 和 MSG，验证 MSG 二进制内容完整传到文档持久化接口。附件选择与大小边界用例通过 7 项，已有附件传输用例通过 73 项，Vite 生产构建通过。完整输入框套件通过 113 项，其余两项在基线 `6a211621a4` 同样失败，分别涉及企业版 Agent 模式控件和 Owner 停止回调。
