# Multica 本地 ACP 运行时接入

Multica 的自定义 Profile 使用 `kimi` 协议族和本机启动器绝对路径。daemon 探测版本后，以 `acp` 子命令启动适配脚本。脚本将其余参数原样传给当前 checkout 的 `jiuwenswarm-acp`，由它连接已经运行的 Gateway。ACP 和模型配置沿用现有入口。

2026-11-20 在 macOS 验证了启动器版本探测、ACP 初始化、建会话和流式文本回复。两组现有 ACP 测试共 9 项通过。Multica daemon 0.11.1 注册 JiuwenSwarm 0.2.9b5 为在线运行时，冒烟事项 DEV-4 的运行进入 completed，事项收到了 `JIUWEN_ACP_OK`。

首版支持 Linux 和 macOS 启动脚本，在 macOS 上完成实际验证。JiuwenSwarm ACP 声明 `loadSession: false`。跨运行恢复、MCP 配置转发和 Windows 启动未纳入本次验收。
