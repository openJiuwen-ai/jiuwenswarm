# Submit a JiuwenSwarm bug report from Web chat

The 0.2.9 backport brings the [issue-reporting contract](../specs/jiuwenswarm/agents/harness/common/tools/S_02_report-issue.md) to personal Web chat. It extends the existing GitCode client, validates reports against the Bug Report form, and uses the release's existing confirmation card. The workspace integration token controls the GitCode account used for submission. A SQLite receipt prevents an approval replay from attempting a second POST.

The adapter registers the tools for interactive single-agent Web chat. Team reporting and the dedicated issue-review panel belong to the later implementation.

## Verification

On Windows, the report-issue and interrupt-helper suites passed 90 tests with the release-pinned Agent Core (`93b86fb8`) and Gateway (`43a1d502`). The tests exercise Web confirmation, the exact reviewed payload, rejection, a changed template, and approval replay using simulated GitCode HTTP responses. Live GitCode publication was outside the test run.
