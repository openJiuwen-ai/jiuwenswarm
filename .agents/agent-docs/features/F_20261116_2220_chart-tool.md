# generate_chart Zero-Dependency Vector SVG Visualization Tool

## 1. 背景与目标
在多智能体数据分析与任务汇报场景中，智能体通常需要将结构化数据以直观的可视化图表交付给用户。
但标准环境通常未安装庞大的图形渲染依赖（如 `matplotlib`、`pillow`、`plotly`），
引入这类依赖会导致安装体积过大及各系统二进制兼容问题。

本特性实现 `generate_chart` 工具，提供基于 Python 标准库实现的纯矢量 SVG 现代图表生成能力：
- 零第三方外部依赖，纯 Python 标准库生成高质量 SVG；
- 支持多种主流图表形态：柱状图（`bar`）、折线图（`line`）、饼图（`pie`）、环形图（`donut`）与核心指标看板卡片（`metric_card`）；
- 严格遵循现代设计配色（Tailwind 调色规范），自适应背景与网格线；
- 自动写入工作区并返回 Markdown 图片引用，用户在会话与前端中可无缝缩放预览。

## 2. 关键能力
- **自适应刻度与网格**：根据数据最大值自动计算 4 等分刻度线与数值标签。
- **几何与扇区数学计算**：使用极坐标几何算法（`math.cos`, `math.sin`）精确渲染圆弧切片与图例百分比。
- **安全与边界防护**：对标签与数值进行 XML/HTML 转义，避免注入；严格限制在工作区内防止越界；处理 0 值、负值与空数据集。
- **系统接线**：完成系统共享工具注册、权限集合定义、渐进式检索元数据与前端图标映射。

## 3. 验证与测试

  数据长度不匹配、非数值数据、空标题、数值 0 渲染、负值防护、全 0 饼图、工作区越界防护拦截等
  16 项测试，16/16 全部通过。
