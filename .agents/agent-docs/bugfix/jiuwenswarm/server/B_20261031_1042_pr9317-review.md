# PR 9317 检视修复

## 现象、根因与修复

[PR 9317](https://gitcode.com/openJiuwen/jiuwenswarm/pull/9317/discuss) 的 openJiuwen-bot 指出两处问题：

- 评论 197114473：插件主智能体校验将七个操作数放在同一 if 中。拆成 profile、team、sub_mode/submode、实际团队成员四组顺序校验，每条最多两个操作数，保持原短路顺序、异常信息和获取服务前拒绝的行为。
- 评论 197114707：Front 保留未调用的旧启动链，含缺失导入引用。删除 `_start_runtime_backend`、`_preload_runtime_backend`、`_configure_openjiuwen_logging`、`_apply_runtime_entry_patches`、`_spawn_teammate_bootstrap` 及其内部辅助实现，共 245 行。实际入口仍是 `_run` → `_start_supervisor` → Worker；日志、补丁与预加载由 `worker/runtime_backend.py` 承担，队友引导由 `worker/capabilities.py` 承担。不为不可达旧代码补导入或重建第二条启动路径。

本次不改变插件主智能体限制或 Front/Worker 职责契约，无需调整 spec。
