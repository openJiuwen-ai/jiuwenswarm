# 腾讯文档使用指引

本技能配合 `tencent-docs` MCP server（腾讯文档官方 MCP，端点 `https://docs.qq.com/openapi/mcp`）使用，管理用户本人的腾讯文档空间（docs.qq.com 个人版）。调用腾讯文档工具时必须遵守以下规则。

> 工具名与参数以实际 `tools/list` 返回为准——官方提示工具参数可能更新，**禁止凭记忆或本文档中的示例名传参**；对不熟悉的工具先读取其 schema 再调用。

## 1. 能力概览

官方 MCP 覆盖腾讯文档主要文档类型：

| 类型 | 定位 | 指引深度 |
| --- | --- | --- |
| 在线文档（word） | 会议纪要、报告、大纲、图文内容 | **重点**，见第 4 节 |
| 在线表格（excel）/ 智能表格 | 数据录入、整理、统计、清单管理 | **重点**，见第 4 节 |
| 幻灯片（slide） | 汇报材料、演示文稿 | **重点**，见第 4 节 |
| 思维导图（mind）/ 流程图（flowchart） | 结构化梳理 | 简要说明：可创建与编辑，按需使用 |
| 收集表 / 智能画布（smartcanvas） | 数据收集、自由排版 | 简要说明：按需使用 |

文档空间以节点（node）组织：每个文档/文件夹有唯一节点标识，文件夹可嵌套；删除操作区分 `current`（单个节点）与 `all`（递归）两种模式。

## 2. 工具选择策略

- **先定位，再操作**：对已有文档做任何读取/编辑前，先用搜索工具按关键词定位目标文档，确认标题与类型无误后再执行——避免误改同名文档；无结果时放宽条件（简化关键词、扩大范围）并明示已尝试的策略。
- **读取优先**：回答"文档里写了什么"类问题时，先搜索 → 再读取正文 → 基于真实内容回答，不要编造文档内容。
- **参数以实时 schema 为准**：调用任何工具前先确认其 `tools/list` 中的参数定义；参数不确定时先小范围试调（如先读一行/一段）再批量执行。
- **空间整理**：新建文件夹、移动文档等整理类操作属于低频写操作，同样走第 3 节确认纪律。

## 3. 写操作两阶段确认纪律（强制，不可绕过）

文档创建/更新/删除一经执行即在用户的腾讯文档空间生效，**服务端没有二次确认机制**。以下纪律由本技能强制约束，必须严格执行：

1. 执行任何写操作（创建文档/表格/幻灯片、更新内容、删除节点、移动节点、修改权限）前，**完整展示操作预览**：目标位置（文件夹/父节点）、文档类型与标题、写入或变更的内容摘要（删除/移动则逐项列出对象清单与影响）。
2. **停止本轮，不再调用任何工具**，等待用户明确许可（"确认"/"可以"/"ok"）。
3. 用户许可后才执行；未获许可不得执行，也不得在回复中把「已创建/已修改」作为结论。

铁律：

- **展示预览后必须停下等用户回复，不能在同一轮里自己确认自己**。
- 用户拒绝或超时未确认时，终止操作并如实告知，不得重试诱导。
- 删除类操作**默认仅 `current`（单个节点）**；`all`（递归删除整个文件夹）必须经用户显式确认，并在预览中列出将被删除的全部子节点数量。
- 权限变更（只读 ↔ 可编辑）同样先预览后执行。

## 4. 三类核心场景配方

### 4.1 在线文档（纪要/报告 → 成文 → 润色）

1. 将对话中的原始材料（会议纪要、大纲、零散要点）整理为结构化文稿；
2. 走第 3 节预览确认后创建在线文档并写入；
3. 二次编辑（润色、扩写、调整结构）同样先给出变更摘要再执行；
4. 产出后主动提供文档链接，并按第 5 节引导分享。

### 4.2 在线表格（对话数据 → 结构化录入 → 整理统计）

1. 把对话中的清单/台账/统计数据整理为行列结构，向用户展示拟写入的表头与行数；
2. 大批量写入前**先估算调用次数**（见第 6 节配额），行数较多时分批写入并告知进度；
3. 写入后读取校验，向用户报告实际写入行列数；
4. 整理统计类需求（排序、筛选、汇总）优先在表格工具能力内完成，能力不足时读取数据后在对话中给出统计结果。

### 4.3 幻灯片（大纲/已有文档 → 成片）

1. 以用户提供的大纲或已有文档为蓝本，先给出拟生成的幻灯片结构（页数与每页要点）；
2. 确认后生成幻灯片；
3. 逐页调整（改标题、换要点、调顺序）按第 3 节纪律执行；
4. 完成后引导生成分享链接交付（第 5 节）。

## 5. 分享与权限

- 生成分享链接是交付 Agent 产出物的标准动作：文档创建完成后，主动询问是否需要分享链接。
- 权限档位**默认建议只读**；设置「可编辑」需用户明示（链接持有者可改文档，风险如实提示）。
- 链接面向外部人员时，提醒用户检查文档内容是否含敏感信息（脱敏检查）。
- 权限变更（收紧或放宽）走第 3 节预览确认纪律。

## 6. 配额与频率

- 官方按天限频，各账号档位的每日调用上限**以授权页实时展示为准**（官方不同页面口径不一致，且有限时优惠活动，不要向用户引用写死的数字）。
- 批量操作（大批量写行、批量整理空间）前先估算所需调用次数并告知用户预计消耗；明显超出当日剩余配额时，建议拆分到多天执行。
- 触发限频（429）时如实转述、降速或改日再试，**禁止重试风暴**。

## 7. 错误处理

- **401 / 鉴权失败**：Token 失效或填写错误 → 引导用户在腾讯文档空间内重新获取（空间列表进入目标空间 → 右上角「≡」→「使用MCP」→「获取MCP token」→ 复制或重置），并在连接器设置中更新后重连。
- **429 / 超出频率**：当日调用达上限 → 如实告知配额档位，建议升级会员或次日再继续；不得自动重试轰炸。
- **404 / 无权限**：文档不存在或不属于当前账号 → 检查文档归属、所在空间与分享状态；Token 只能访问生成该 Token 的账号有权限、且官方 MCP 允许操作的内容。
- **网络/端点异常**：官方端点临时不可用 → 如实转述，稍后重试；不要臆造"已成功"的结果。

## 8. 凭证说明与换号指引

- 连接凭证为「个人 MCP Token」，在腾讯文档**空间内**生成（进入空间 → 右上角「≡」→「使用MCP」→「获取MCP token」），**按空间生成、有效期一年**；操作多个空间的内容前，确认当前 Token 生成于哪个空间，权限不符时引导用户在对应空间重新生成。
- 官方获取资格以页面实时校验为准（官方文档提示需通过超级会员/超级会员Plus 校验）；用户无法获取 Token 时如实告知，不要绕过。
- Token 仅加密保存在本机，不要将其写入文档正文、聊天记录或任何文件；怀疑泄露或到期时，在同一菜单点「重置」作废旧 Token 并生成新 Token，然后在连接器设置中更新。
- 换账号必须断开连接后用新账号的空间重新生成 Token 再连接；断开连接即清除本机授权；连接失败重试时系统可能要求重新填写 Token，属正常安全行为。
